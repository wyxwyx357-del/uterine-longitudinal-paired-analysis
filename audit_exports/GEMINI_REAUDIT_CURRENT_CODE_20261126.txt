# Feature extraction output schema

## Formal cross-module contract

The formal output of the locked current workflow is:

```text
01_feature_extraction/outputs/FINAL_DYNAMIC_FEATURES.csv
```

It is produced by the unchanged frozen runtime:

```text
01_feature_extraction/frozen_runtime_20261126/run_final_batch.py
```

through the repository wrapper:

```text
01_feature_extraction/run_feature_extraction.py
```

The wrapper copies the exact frozen `FINAL_DYNAMIC_FEATURES.csv` to the stable
module output path. It does not recalculate, impute, tune or filter features.

`auto_features.csv` is now **compatibility only**. `export_auto_features.py`
may generate it as a projected/renamed subset for older code, but the formal
source of truth is `FINAL_DYNAMIC_FEATURES.csv`.

## Main fields used by longitudinal analysis

| canonical longitudinal field | source in FINAL_DYNAMIC_FEATURES.csv | meaning |
|---|---|---|
| exam_id | case_id | examination ID |
| anterior_amplitude | anterior_amplitude | anterior radial stretch activity amplitude |
| posterior_amplitude | posterior_amplitude | posterior radial stretch activity amplitude |
| r2_frequency_cpm | R2_frequency_cpm | current frozen posterior longitudinal R2 |
| anterior_er | anterior_ER_mean_paired | anterior ER summary over paired windows |
| posterior_er | posterior_ER_mean_paired | posterior ER summary over paired windows |
| mse | record_MSE_time_equal | time-equal record ER-MSE |
| m1_prop_rate_min_per_min | m1_prop_rate_min_per_min | lower-bound significant propagation activity rate |
| tracking_valid_fraction | raw_valid_fraction | A0 raw usable support fraction |

The longitudinal loader maps `case_id -> exam_id` exactly and requires one row
per examination. It does not use name-based fuzzy matching.

## QC / provenance retained when available

The master table also retains current-workflow status fields such as:

- pipeline_version
- a0_status
- anterior_amplitude_status / posterior_amplitude_status
- mse_status / mse_decomposition_status
- record_MSE_z and MSE decomposition terms
- m1_status / m1_failure_reason / m1_algorithm_version
- m1_prop_rate_max_per_min / count range / effective observation time
- R2_status / R2_failure_reason / R2_version
- R2_retained_posterior_region_count

## Missing-data rule

Measurement failure is never converted to zero.

```text
tracking failure != 0
R2 failure      != 0 cpm
M1 no support   != 0 activity/min
MSE unavailable != 0
amplitude fail  != 0
```

Missing or failed measurements remain blank / NaN with status and failure
reason where the frozen workflow provides them.

## Interpretation boundaries

- **R2** = local wall-tangent tissue-motion dominant frequency candidate.
- **M1** = significant propagation-activity candidate rate.
- **ER** = directional-energy representation.
- **MSE** = anterior/posterior ER coordination/difference candidate.
- **Amplitude** = radial stretch activity amplitude.

None of these automatically equals a confirmed physiological peristaltic-wave
count or externally validated clinical biomarker.

## Outcome blindness

The formal feature-extraction workflow is outcome blind. Its locked spec states:

```text
outcomes_read = false
```

Pregnancy outcomes enter only in the longitudinal/statistical module.

# Engineering hardening after Gemini final audit — 2026-11-26

Revision:

```text
20261126_gemini_audit_fix1
```

This revision is intentionally limited to orchestration, identity preservation,
input validation and reproducibility safeguards. It does **not** change the
locked mathematical definitions or thresholds of A0, amplitude, ER, MSE, M1 or
R2.

## Fixed BLOCKER 1 — source-lock verification

- corrected `verify_environment.py` so `SOURCE_LOCK.json` paths are resolved
  relative to `frozen_runtime_20261126/`, where the locked source actually lives;
- added repository `.gitattributes` with LF line endings for text source files;
- hash verification canonicalizes text line endings to LF, preventing Windows
  `core.autocrlf` from producing false source-lock failures;
- added `01_feature_extraction/PIPELINE_ORCHESTRATION_LOCK.json` for the formal
  entry/wrapper/spec files that were previously outside `SOURCE_LOCK.json`.

## Fixed BLOCKER 2 — one R2 case must not abort the cohort

- `r2_frozen/run_tracking_batch.py` now merges all successfully completed cases
  even when other cases fail;
- failed cases are recorded in `merged_results/failed_cases.csv` and in
  `resumable_status.json`;
- downstream cache discovery ignores caches from cases whose tracking state is
  not `complete`;
- `run_final_batch.py` carries failed/invalid R2 cases forward as
  `R2_frequency_cpm = NaN` plus `R2_status` and `R2_failure_reason`;
- an unexpected whole-stage R2 exception is isolated from A0/M1/MSE so the final
  examination table can still be produced with explicit R2 failure status.

No failed R2 measurement is replaced by zero.

## Fixed BLOCKER 3 — case/exam ID type stability

- manifest `case_id` remains a string from CSV input onward;
- R2 pandas CSV readers explicitly preserve `case_id` as string;
- compatibility export preserves `case_id` before renaming to `exam_id`;
- longitudinal clinical/feature merge preserves exam identifiers as strings;
- dynamic feature rows whose exam IDs do not exist in the clinical table now
  raise an explicit error instead of being silently dropped.

This protects identifiers such as `00123` from accidental conversion to
`123`.

## Fixed MAJOR — relative manifest paths

Formal manifest path fields are resolved relative to the manifest file's own
directory before A0/R2 processing:

- video
- annotation
- pose
- a0_spacetime_cache
- r2_tracking
- r2_nodes

R2 therefore receives absolute paths even when the user supplies portable
relative manifest paths.

## Explicit geometry preflight

The current R2 algorithm still has its existing source-video geometry
requirement:

```text
1260 x 910
```

This algorithmic assumption was **not changed**. Instead,
`verify_tracking_inputs.py` now reports
`unsupported_video_geometry:<width>x<height>;expected_1260x910` before
tracking. The incompatible case is isolated rather than allowed to crash the
cohort.

Changing the R2 background ROI or geometry normalization would be a measurement
algorithm change and is outside this engineering revision.

## Formal manifest cleanup

The formal manifest template no longer advertises
`a0_tracks_cache` / `a0_layout_cache`, because the formal
`run_final_batch.py` does not consume them.

The deprecated broken `run_final_batch_full.py` wrapper was removed from the
formal runtime. Git history retains it for audit.

## Lock state after fixes

- orchestration lock: verified against current Git blob SHAs;
- modified R2 source files: verified against current canonical-LF SHA256 values
  in `SOURCE_LOCK.json`;
- `algorithm_definition_unchanged = true` is recorded in the lock/spec.

## Still intentionally unchanged

The following were **not** modified:

- A0 tracking parameters;
- amplitude definition;
- ER 20 s / 0.5–5 cpm directional spectrum definition;
- record MSE formulas;
- M1 thresholds/identity/count definition;
- R2 0.5–5.0 cpm grid and 0.05 cpm step;
- R2 fixed-point/continuous-segment rules;
- R2 high + validated-stable-medium retention;
- final posterior retained-region equal-mean aggregation;
- R2 hard-coded background ROI / source geometry algorithm.

#!/usr/bin/env python3
"""Run the frozen dynamic pipeline and publish the formal feature table.

The frozen runtime is invoked unchanged. This wrapper does not recalculate,
impute, tune or filter dynamic features. It only:
1) runs the locked current workflow;
2) copies FINAL_DYNAMIC_FEATURES.csv to the stable module output path;
3) optionally writes the legacy auto_features.csv compatibility projection.

Pregnancy outcomes are never read here.
"""
from __future__ import annotations

import argparse
import os
from pathlib import Path
import shutil
import subprocess
import sys


ROOT = Path(__file__).resolve().parent
RUNTIME = ROOT / "frozen_runtime_20261126"
FROZEN_ENTRY = RUNTIME / "run_final_batch.py"
EXPORTER = ROOT / "export_auto_features.py"
FORMAL_OUTPUT = ROOT / "outputs" / "FINAL_DYNAMIC_FEATURES.csv"
LEGACY_OUTPUT = ROOT / "outputs" / "auto_features.csv"


def atomic_copy(source: Path, destination: Path) -> None:
    destination.parent.mkdir(parents=True, exist_ok=True)
    tmp = destination.with_suffix(destination.suffix + ".tmp")
    shutil.copyfile(source, tmp)
    os.replace(tmp, destination)


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("--manifest", type=Path, required=True)
    parser.add_argument(
        "--work-dir",
        type=Path,
        default=ROOT / "outputs" / "frozen_run",
        help="Internal frozen-runtime work directory; use a new directory for a new formal run.",
    )
    parser.add_argument(
        "--final-features",
        type=Path,
        default=FORMAL_OUTPUT,
        help="Stable formal output consumed by longitudinal analysis.",
    )
    parser.add_argument(
        "--compat-auto-features",
        type=Path,
        default=LEGACY_OUTPUT,
        help="Optional legacy projected alias; set to an empty string is not supported.",
    )
    parser.add_argument("--no-compat-auto-features", action="store_true")
    parser.add_argument("--r2-workers", type=int, default=1)
    parser.add_argument("--resume", action="store_true")
    parser.add_argument("--skip-r2", action="store_true")
    parser.add_argument("--skip-a0", action="store_true")
    args = parser.parse_args()

    if not FROZEN_ENTRY.is_file():
        raise FileNotFoundError(FROZEN_ENTRY)
    if not args.manifest.is_file():
        raise FileNotFoundError(args.manifest)

    env = os.environ.copy()
    previous = env.get("PYTHONPATH", "")
    env["PYTHONPATH"] = (
        str(RUNTIME)
        if not previous
        else str(RUNTIME) + os.pathsep + previous
    )

    command = [
        sys.executable,
        str(FROZEN_ENTRY),
        "--manifest",
        str(args.manifest.resolve()),
        "--output",
        str(args.work_dir.resolve()),
        "--r2-workers",
        str(args.r2_workers),
    ]
    if args.resume:
        command.append("--resume")
    if args.skip_r2:
        command.append("--skip-r2")
    if args.skip_a0:
        command.append("--skip-a0")

    result = subprocess.run(command, cwd=RUNTIME, env=env, check=False)
    if result.returncode != 0:
        return result.returncode

    frozen_table = args.work_dir / "FINAL_DYNAMIC_FEATURES.csv"
    if not frozen_table.is_file():
        raise FileNotFoundError(
            f"Frozen run completed without expected table: {frozen_table}"
        )

    # Preserve the exact frozen table as the formal cross-module contract.
    atomic_copy(frozen_table, args.final_features)

    # Compatibility only: projected/renamed subset for older scripts.
    if not args.no_compat_auto_features:
        export = subprocess.run(
            [
                sys.executable,
                str(EXPORTER),
                "--input",
                str(args.final_features.resolve()),
                "--output",
                str(args.compat_auto_features.resolve()),
            ],
            cwd=ROOT,
            env=env,
            check=False,
        )
        if export.returncode != 0:
            return export.returncode

    print(f"formal_features={args.final_features.resolve()}")
    if not args.no_compat_auto_features:
        print(f"compat_auto_features={args.compat_auto_features.resolve()}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

#!/usr/bin/env python3
"""Convert the frozen batch table to the longitudinal-analysis feature contract.

This script only renames/selects fields. It does not recalculate, impute, tune,
or filter any dynamic feature, and it never reads a pregnancy outcome.
"""
from __future__ import annotations

import argparse
import hashlib
import json
import os
from pathlib import Path

import pandas as pd


ROOT = Path(__file__).resolve().parent
DEFAULT_INPUT = ROOT / "outputs" / "FINAL_DYNAMIC_FEATURES.csv"
DEFAULT_OUTPUT = ROOT / "outputs" / "auto_features.csv"

RENAME = {
    "case_id": "exam_id",
    "R2_frequency_cpm": "r2_frequency_cpm",
    "anterior_ER_mean_paired": "anterior_er",
    "posterior_ER_mean_paired": "posterior_er",
    "record_MSE_time_equal": "mse",
    "raw_valid_fraction": "tracking_valid_fraction",

    "exam_id",
    "anterior_amplitude",
    "posterior_amplitude",
    "r2_frequency_cpm",
    "anterior_er",
    "posterior_er",
    "mse",
    "m1_prop_rate_min_per_min",

    "video_qc",
    "pose_source",

    "pipeline_version",
    "a0_status",
    "anterior_amplitude_status",
    "posterior_amplitude_status",
    "mse_status",
    "mse_decomposition_status",
    "m1_status",
    "m1_failure_reason",
    "m1_algorithm_version",
    "R2_status",
    "R2_failure_reason",
    "R2_retained_posterior_region_count",

    "record_mean_bias_sq",
    "record_sd_scale_sq",
    "record_time_shape_term",
    "effective_observation_seconds",
    "m1_prop_count_min",
    "m1_prop_count_max",
]


def sha256(path: Path) -> str:
    h = hashlib.sha256()
    with path.open("rb") as stream:
        for block in iter(lambda: stream.read(1024 * 1024), b""):
            h.update(block)
    return h.hexdigest()


def atomic_csv(frame: pd.DataFrame, path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_suffix(path.suffix + ".tmp")
    frame.to_csv(tmp, index=False)
    os.replace(tmp, path)


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("--input", type=Path, default=DEFAULT_INPUT)
    parser.add_argument("--output", type=Path, default=DEFAULT_OUTPUT)
    args = parser.parse_args()

    if not args.input.is_file():
        raise FileNotFoundError(args.input)

    source = pd.read_csv(args.input, dtype={"case_id": str})
    source["case_id"] = source["case_id"].astype(str).str.strip()
    if "case_id" not in source.columns:
        raise ValueError("Frozen table must contain case_id")
    if source["case_id"].isna().any():
        raise ValueError("case_id contains missing values")
    if source["case_id"].astype(str).str.strip().eq("").any():
        raise ValueError("case_id contains blank values")
    if source["case_id"].duplicated().any():
        raise ValueError("case_id must be unique in FINAL_DYNAMIC_FEATURES.csv")

    output = source.rename(columns=RENAME).copy()

    # Keep a stable schema. Empty technical metadata stays missing; it is never
    # synthesized from unrelated status fields.
    for column in PRIMARY_COLUMNS:
        if column not in output.columns:
            output[column] = pd.NA

    keep = PRIMARY_COLUMNS + [
        column for column in PROVENANCE_COLUMNS
        if column in output.columns and column not in PRIMARY_COLUMNS
    ]
    output = output[keep].copy()

    # Numeric coercion preserves failed/missing measurements as NaN.
    numeric = [
        "anterior_amplitude",
        "posterior_amplitude",
        "r2_frequency_cpm",
        "anterior_er",
        "posterior_er",
        "mse",
        "m1_prop_rate_min_per_min",
        "tracking_valid_fraction",
        "R2_retained_posterior_region_count",
        "record_MSE_z",
        "record_mean_bias_sq",
        "record_sd_scale_sq",
        "record_time_shape_term",
        "effective_observation_seconds",
        "m1_prop_count_min",
        "m1_prop_count_max",
    ]
    for column in numeric:
        if column in output.columns:
            output[column] = pd.to_numeric(output[column], errors="coerce")

    atomic_csv(output, args.output)
    manifest = {
        "clinical_outcome_read": False,
        "operation": "field projection only; no feature recalculation or imputation",
        "input": str(args.input.resolve()),
        "input_sha256": sha256(args.input),
        "output": str(args.output.resolve()),
        "output_sha256": sha256(args.output),
        "rows": int(len(output)),
        "exam_id_unique": bool(output["exam_id"].is_unique),
        "columns": list(output.columns),
        "renamed_fields": RENAME,
    }
    manifest_path = args.output.with_name(args.output.stem + "_export.json")
    manifest_path.write_text(
        json.dumps(manifest, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )

    print(f"rows={len(output)}")
    print(f"output={args.output.resolve()}")
    print(f"manifest={manifest_path.resolve()}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

```text
→ background rigid correction
→ cervix-to-fundus local wall-tangent displacement
→ 0.5–5 cpm candidate fitting
→ technical/reproducibility rules
→ retained posterior regions
→ R2_frequency_cpm
```

## Current primary definition

- motion direction: local wall tangent, cervix → fundus
- frequency band: 0.5–5.0 cpm
- grid step: 0.05 cpm
- formal wall: posterior only
- primary regions: high confidence + independently validated stable medium
- spatial regions: cervical / middle / fundal
- exam-level aggregation: equal mean over retained posterior regions

正式检查级字段：

```text
R2_frequency_cpm
```

如果没有任何 retained posterior region：

```text
R2_frequency_cpm = NaN
R2_status = no_retained_posterior_region
```

失败不写成 0 cpm。

def sha256(path: Path) -> str:
    h = hashlib.sha256()
    with path.open("rb") as f:
        for block in iter(lambda: f.read(1024 * 1024), b""):
            h.update(block)
    return h.hexdigest()


def text(v):
    return "" if v is None else str(v).strip()


def optional_path(v):
    s = text(v)
    return Path(s) if s else None


def save_json(path: Path, obj):
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_suffix(path.suffix + ".tmp")
    tmp.write_text(json.dumps(jsonable(obj), ensure_ascii=False, indent=2, allow_nan=False), encoding="utf-8")
    os.replace(tmp, path)


def load_npz(path: Path) -> dict:
    with np.load(path, allow_pickle=False) as z:
        return {k: z[k] for k in z.files}


def validate_spacetime(maps: dict):
    needed = {"A", "epsilon", "valid_mask", "s", "interval_start_s", "interval_end_s", "interval_center_s", "interval_dt_s"}
    missing = needed - set(maps)
    if missing:
        raise ValueError("A0 spacetime cache missing keys: " + ",".join(sorted(missing)))
    a = np.asarray(maps["A"], float)
    v = np.asarray(maps["valid_mask"], bool)
    s = np.asarray(maps["s"], float)
    t = np.asarray(maps["interval_center_s"], float)
    if a.shape != v.shape or a.shape != (len(t), 2, len(s)):
        raise ValueError("A0 spacetime cache shape mismatch")
    if len(t) < 3 or not np.isfinite(t).all() or np.any(np.diff(t) <= 0):
        raise ValueError("A0 spacetime cache invalid timeline")
    nominal = float(np.asarray(maps.get("nominal_interval_s", 2.0)).reshape(-1)[0])
    if abs(nominal - 2.0) > 1e-6:
        raise ValueError(f"Expected frozen nominal_interval_s=2.0, got {nominal}")

def write_csv(path: Path, rows: list[dict]):
    fields = []
    for row in rows:
        for key in row:
            if key not in fields:
                fields.append(key)
    with path.open("w", newline="", encoding="utf-8-sig") as f:
        w = csv.DictWriter(f, fieldnames=fields, extrasaction="ignore")
        w.writeheader(); w.writerows(rows)


def run_command(
    cmd: list[str],
    cwd: Path,
    log: Path,
    *,
    allow_failure: bool = False,
) -> int:
    print("RUN:", " ".join(cmd), flush=True)
    with log.open("w", encoding="utf-8") as out:
        p = subprocess.run(
            cmd,
            cwd=cwd,
            stdout=out,
            stderr=subprocess.STDOUT,
            check=False,
        )
    if p.returncode and not allow_failure:
        raise RuntimeError(f"Command failed ({p.returncode}); see {log}")
    return int(p.returncode)

def load_manifest(path: Path):
    manifest_path = path.resolve()
    manifest_dir = manifest_path.parent
    with manifest_path.open(
        "r", encoding="utf-8-sig", newline=""
    ) as f:
        rows = list(csv.DictReader(f))
    if not rows:
        raise ValueError("Manifest is empty")

    ids = []
    for row in rows:
        case_id = text(row.get("case_id"))
        row["case_id"] = case_id
        ids.append(case_id)
        for key in MANIFEST_PATH_FIELDS:
            raw = text(row.get(key))
            if not raw:
                continue
            value = Path(raw)
            if not value.is_absolute():
                value = manifest_dir / value
            row[key] = str(value.resolve())

    if any(not case_id for case_id in ids):
        raise ValueError("case_id must be nonempty")
    if len(ids) != len(set(ids)):
        raise ValueError("case_id must be unique")
    return rows

TEXT_SUFFIXES = {".py", ".json", ".csv", ".md", ".txt", ".yml", ".yaml"}


def canonical_bytes(path: Path) -> bytes:
    """Hash repository text canonically as LF, independent of Windows CRLF checkout."""
    data = path.read_bytes()
    if path.suffix.lower() in TEXT_SUFFIXES:
        data = data.replace(b"\r\n", b"\n").replace(b"\r", b"\n")
    return data


def git_blob_sha1(path: Path) -> str:
    data = canonical_bytes(path)
    return hashlib.sha1(
        b"blob " + str(len(data)).encode("ascii") + b"\0" + data
    ).hexdigest()


def sha256(path: Path) -> str:
    return hashlib.sha256(canonical_bytes(path)).hexdigest()

    ids=np.asarray(sorted(node['sections']),int)
    for block in np.split(ids,np.flatnonzero(np.diff(ids)!=1)+1):
        if len(block)<3:
            continue

        phase_fits,availability=retained_phase_fits(node,block,s,dt)
        measurement=_describe_arrival(block,arrival,np.asarray(s),dt,phase_fits,RadialWaveConfig())

def _maximum_bipartite_matching_count(left_nodes, adjacency):
    """Deterministic maximum cardinality matching; returns number of pairs."""
    owner={}
    def augment(left, seen):
        for right in sorted(adjacency.get(left, ())):
            if right in seen:
                continue
            seen.add(right)
            if right not in owner or augment(owner[right], seen):
                owner[right]=left
                return True
        return False
    return sum(augment(left,set()) for left in sorted(left_nodes))

"""Whole-activity strength after ownership; no new detection or wave counts.

Median per-native-section phase-footprint RMS is compared with the maximum

def filtered_runs(signal, valid, time_s):
    y = np.asarray(signal, float); m = np.asarray(valid, bool)
    t = np.asarray(time_s, float)
    if y.shape != m.shape or y.shape[0] != len(t) or len(t) < 3 or np.any(np.diff(t) <= 0):
        raise ValueError('Expected native time-first signals and matching validity')
    result = np.full_like(y, np.nan)
    minimum = max(3, int(np.ceil(12/np.median(np.diff(t)))))
    for col in np.ndindex(y.shape[1:]):
        key = (slice(None),)+col
        supported = m[key] & np.isfinite(y[key])
        for a, b in np.flatnonzero(np.diff(np.r_[False, supported, False])).reshape(-1, 2):
            if b-a >= minimum:
                result[(slice(a,b),)+col] = band_limited_signal(y[(slice(a,b),)+col], t[a:b])
    return result


class RigidReference:
    """Translate a candidate footprint over complete native noise supports.

    Exact section offsets are retained, including gaps. Temporal offsets and
    inclusive durations are rounded to the reference's native frames, never
    interpolated. Windows crossing a missing reference sample are excluded.
    """
    def __init__(self, banks):
        self.banks = []
        for name, y, t in banks:
            y = np.asarray(y, float); t = np.asarray(t, float)
            if y.ndim != 3 or len(y) != len(t) or len(t) < 3:
                raise ValueError('Expected rigid time x wall x section arrays')
            dt = float(np.median(np.diff(t)))
            if not np.allclose(np.diff(t), dt, rtol=1e-5, atol=1e-9):
                raise ValueError('Reference time must be uniform')
            good = np.isfinite(y)
            energy = np.concatenate([np.zeros((1,)+y.shape[1:]),
                                     np.cumsum(np.where(good, y*y, 0), axis=0)])
            missing = np.concatenate([np.zeros((1,)+y.shape[1:], int),
                                      np.cumsum(~good, axis=0)])
            self.banks.append((name, energy, missing, dt))

    def maximum(self, sections, starts_s, ends_s):
        sections = np.asarray(sections, int)
        offsets = sections-sections[0]
        origin = float(np.min(starts_s))
        maximum = None; count = 0; by_bank = {}
        for name, energy, missing, dt in self.banks:
            lo = np.rint((np.asarray(starts_s)-origin)/dt).astype(int)
            hi = np.rint((np.asarray(ends_s)-origin)/dt).astype(int)+1
            duration = hi-lo
            time_count = len(energy)-int(hi.max())
            spatial_count = energy.shape[2]-int(offsets.max())
            if min(time_count, spatial_count) < 1:
                continue
            start = np.arange(time_count)[:, None, None]
            column = np.arange(spatial_count)[None, :, None]+offsets[None, None, :]
            values = []
            for wall in range(energy.shape[1]):
                sums = energy[start+hi, wall, column]-energy[start+lo, wall, column]
                complete = (missing[start+hi, wall, column]-missing[start+lo, wall, column] == 0).all(2)
                rms = np.sqrt(np.maximum(sums, 0)/duration)
                statistic = np.median(rms, axis=2)[complete]
                if len(statistic):
                    values.append(statistic)
            if values:
                pooled = np.concatenate(values)
                value = float(pooled.max()); count += len(pooled)
                by_bank[name] = dict(maximum=value, matched_windows=len(pooled))
                maximum = value if maximum is None else max(maximum, value)
        return dict(maximum_rms=maximum, matched_windows=count, calibration_banks=by_bank)

        raise ValueError('Expected one wall and matching time/section validity')

        start = min(p['start_s'] for p in phases); end = max(p['end_s'] for p in phases)

def process_case(task):
    case_id, source, destination, floor = task
    begin = time.monotonic()
    try:
        before = digest(source)
        with np.load(source, allow_pickle=False) as z:
            maps = dict(z)
        result = count_map(maps, floor)
        if digest(source) != before:
            raise RuntimeError('Source spacetime changed during counting')
        result.update(case_id=case_id, source_spacetime=str(source),
                      source_sha256=before, elapsed_s=time.monotonic()-begin)
        save(destination, result)
        keys = [COUNT, RATE, 'other_significant_activity_count',
                'effective_observation_seconds', 'unresolved_activity_rows',
                'raw_valid_fraction', 'sampled_s_range', 'native_section_count'] + V2_FIELDS
        return dict(case_id=case_id, processing_status=result['status'],
                    failure_reason=result.get('failure_reason'), result_path=str(destination),
                    **{k: result.get(k) for k in keys})
    except Exception as error:
        # Per-case batch boundary only: retain the actual error, never zero.
        failed = dict(case_id=case_id, processing_status='failed',
                      failure_reason=f'{type(error).__name__}: {error}',
                      traceback=traceback.format_exc(), **{COUNT: None, RATE: None})
        save(destination, failed)
        return dict({key: None for key in V2_FIELDS},
                    **{k: v for k, v in failed.items() if k != 'traceback'})

def _blocks(ids):
    ids=np.asarray(ids,int)
    return [x for x in np.split(ids,np.flatnonzero(np.diff(ids)!=1)+1) if len(x)]


def _local_nodes(signal,valid,t,s,parent,span,floor):
    context=np.flatnonzero((t>=parent['start_s']-span)&(t<=parent['end_s']+span))
    times=t[context]
    values=np.full((len(times),len(s)),np.nan)
    columns=[[] for _ in s]
    for col in parent['sections']:
        supported=valid[context,col]&np.isfinite(signal[context,col])
        for run_id,(begin,end) in enumerate(core._runs(supported)):
            if end-begin<3:
                continue
            samples=int(2*np.floor(span/np.median(np.diff(times))/2)+1)
            if end-begin<samples:
                continue
            # Only this parent's buffered slice is read by the auxiliary filter.
            y=measurement_span_mean(signal[context[begin:end],col],times[begin:end],span_s=span)
            values[begin:end,col]=y
            edges=np.r_[0,np.flatnonzero(np.diff(y>=0))+1,len(y)]
            for sequence,(a,b) in enumerate(zip(edges[:-1],edges[1:])):
                peak=a+int(np.argmax(abs(y[a:b])))
                amplitude=float(abs(y[peak]))
                if amplitude<=max(float(floor[col]),1e-12) or peak in (a,b-1):
                    continue
                columns[col].append(dict(column=col,run_id=run_id,sequence=sequence,
                    sign=1 if y[peak]>0 else -1,peak_index=int(begin+peak),
                    peak_time_s=float(times[begin+peak]),amplitude=amplitude,
                    first=int(begin+a),last=int(begin+b-1),
                    start_s=float(times[begin+a]),end_s=float(times[begin+b-1]),
                    left_censored=bool(a==0),right_censored=bool(b==len(y))))
    return context,times,values,columns


def prepare_parent(signal,valid,time_s,space,parent,*,noise_floor,measurement_span_s):
    """Compute local evidence once; support=3/4/5 uses the SAME observations.

    existing measurement span; child ARRIVALS must remain in the unexpanded

        raise ValueError('Invalid frozen noise reference or parent time bounds')

                    velocity_paths_per_s=child['velocity_paths_per_s'] if propagation else None,
                    speed_candidate_paths_per_s=child['velocity_paths_per_s'] if propagation else None,
                    supporting_phase_evidence=[dict(section=int(c),
                        phases=[dict(sign=node_maps[r][int(c)]['sign'],
                            peak_s=node_maps[r][int(c)]['peak_time_s'],
                            observed_start_s=node_maps[r][int(c)]['start_s'],
                            observed_end_s=node_maps[r][int(c)]['end_s'],
                            run_id=node_maps[r][int(c)]['run_id'],
                            amplitude=node_maps[r][int(c)]['amplitude']) for r in child['phase_ridge_ids']]) for c in block],
                    propagation_source='Local nodes through unchanged ridge/pair measurement and pairing',
                    reviewed=False)
                children.append(child)
            options.append(dict(identity=tuple(a['phase_ridge_ids']+b['phase_ridge_ids']),
                                common_sections=block.tolist(),children=children,

def decide_split(prepared,*,minimum_adjacent_support=3,include_signals=False):
    if minimum_adjacent_support not in (3,4,5):
        raise ValueError('This fixed experiment permits adjacent support 3, 4 or 5')
    parent=prepared['parent']
    eligible=[p for p in prepared['options'] if len(p['common_sections'])>=minimum_adjacent_support]
    identities={p['identity'] for p in eligible if not p['conflicts']}
    if len(identities)==1 and not any(p['conflicts'] for p in eligible):
        selected=max((p for p in eligible if not p['conflicts']),key=lambda p:len(p['common_sections']))
        status='split_two';reason='two ordered complete local phase sequences on adjacent native sections'
        children=deepcopy(selected['children'])
        for index,child in enumerate(children,1):
            child['event_id']=f"{parent['event_id']}_child_{index}"
    else:
        children=[]
        tentative=any(n>=2 for n in prepared['turn_counts'].values())
        status='split_ambiguous' if tentative or eligible else 'keep_single'
        reason=('competing identities or inconsistent local order' if eligible else
                'second-turn evidence lacks shared adjacent support' if tentative else 'no supported internal second activity')
    result=dict(parent_candidate_id=parent['event_id'],parent=deepcopy(parent),
        split_status=status,reason=reason,minimum_adjacent_support=minimum_adjacent_support,
        context_time_range_s=prepared['context_time_range_s'],

        conflict_reasons=sorted({flag for p in eligible for flag in p['conflicts']}),
        local_turn_counts=prepared['turn_counts'],event_count=None,event_frequency=None)
    if include_signals:
        result['local_observations']=prepared['local_observations']
    return result

"""Revalidate retained-direction evidence before cross-wall direction reporting.

This is an experimental reconciliation layer.  It does not create candidates,

DIRECTIONS = ('C2F', 'F2C')


def _longest_adjacent(ids):
    ids = np.asarray(sorted(set(ids)), int)
    return max((len(block) for block in np.split(
        ids, np.flatnonzero(np.diff(ids) != 1) + 1)), default=0)


def _adjacent_blocks(ids):
    ids = np.asarray(sorted(set(ids)), int)
    if not len(ids):
        return []
    return [block for block in np.split(
        ids, np.flatnonzero(np.diff(ids) != 1) + 1) if len(block)]


def _phase_subset_matches(left, right, tolerance_s):
    """Allow extra local phases while matching the smaller signed sequence."""
    smaller, larger = (left, right) if len(left) <= len(right) else (right, left)
    smaller = sorted(smaller, key=lambda phase: phase['peak_s'])
    larger = sorted(larger, key=lambda phase: phase['peak_s'])
    first_available = 0
    matches = []
    for phase in smaller:
        choices = [(abs(phase['peak_s'] - larger[j]['peak_s']), j)
                   for j in range(first_available, len(larger))
                   if phase['sign'] == larger[j]['sign']]
        if not choices:
            return False, matches
        distance, index = min(choices)
        if distance > tolerance_s:
            return False, matches
        first_available = index + 1
        matches.append((phase['peak_s'], larger[index]['peak_s']))
    return bool(matches), matches


def compare_identity_without_direction(a, b, span_s, sample_dt_s):
    """Compare activity identity before using either wall's direction label."""
    if a['wall'] == b['wall']:
        raise ValueError('Identity comparison requires different walls')
    tolerance = float(span_s + sample_dt_s)
    shared = sorted(set(a['sections']) & set(b['sections']))
    matched, near, conflicts = [], [], []
    for section in shared:
        arrival_near = (a['arrival_marker'] == b['arrival_marker'] and
                        abs(a['arrival'][section] - b['arrival'][section]) <= tolerance)
        phases_match, _ = _phase_subset_matches(
            a['profile'][section], b['profile'][section], tolerance)
        if arrival_near or phases_match:
            near.append(section)
        if arrival_near and phases_match:
            matched.append(section)
        elif arrival_near or phases_match:
            conflicts.append(section)
    supported = _longest_adjacent(matched) >= 3
    relation = ('shared_identity_supported' if supported else
                'unresolved' if near else 'no_shared_identity_evidence')
    return dict(node_a=a['node_id'], node_b=b['node_id'], relation=relation,
                shared_sections=shared, matched_sections=matched,
                near_sections=near, conflict_sections=conflicts,
                original_directions=[a['direction'], b['direction']],
                original_direction_conflict=(a['direction'] in DIRECTIONS and
                                             b['direction'] in DIRECTIONS and
                                             a['direction'] != b['direction']),
                tolerance_s=tolerance,
                rule='>=3 adjacent arrival-and-phase matches; direction not used for identity')


def revalidate_retained_direction(node, s, sample_dt_s, config=RadialWaveConfig()):
    """Refit each contiguous retained block; never bridge a salience gap."""
    sections = np.asarray(sorted(node['sections']), int)
    blocks = _adjacent_blocks(sections)
    measurements = []
    for block in blocks:
        arrival = np.asarray([node['arrival'][int(section)] for section in block], float)
        measurement = _describe_arrival(
            block, arrival, np.asarray(s, float), float(sample_dt_s), [], config)
        measurements.append(dict(sections=block.tolist(), arrival_time_s=arrival.tolist(),
                                 measurement=measurement))
    block_directions = [item['measurement']['classification'] for item in measurements
                        if item['measurement']['classification'] in DIRECTIONS]
    refit = block_directions[0] if len(set(block_directions)) == 1 else None
    original = node['direction'] if node['direction'] in DIRECTIONS else None
    if original is None:
        status, supported = 'original_direction_unresolved', None
    elif any(direction != original for direction in block_directions):
        status, supported = 'retained_support_conflicts_with_original', None
    elif any(direction == original for direction in block_directions):
        status, supported = 'retained_support_agrees', original
    else:
        status, supported = 'retained_support_unresolved', None
    return dict(node_id=node['node_id'], original_direction=original,

                direction_status=status, retained_sections=sections.tolist(),
                retained_contiguous_blocks=[block.tolist() for block in blocks],
                block_direction_evidence=measurements,
                direction_rule=('each contiguous retained block refit separately; '

"""Event-input ablation only: local averaging at the measurement time scale.

This is not the physiological-band amplitude/ER filter. The detector applies
it separately inside each continuous valid run; missing samples are not filled.
"""
import numpy as np


def measurement_span_mean(values, times, *, span_s):
    """Demean and apply an odd centered boxcar near one measurement interval.

    Reflection pads only the short kernel edge; padded values are not observed
    support. There is no spectral band selection, polynomial detrending or new
    duration parameter independent of the existing radial measurement span.
    """
    y=np.asarray(values,float);t=np.asarray(times,float)
    if y.ndim<1 or y.shape[0]!=len(t) or len(t)<3:
        raise ValueError('Expected time-first values on at least three timestamps')
    differences=np.diff(t)
    if (not np.isfinite(y).all() or not np.isfinite(t).all() or
        np.any(differences<=0) or not np.allclose(differences,np.median(differences),rtol=1e-5,atol=1e-9) or
        not np.isfinite(span_s) or span_s<=0):
        raise ValueError('Expected finite complete values, uniform time and positive measurement span')
    samples=int(2*np.floor(span_s/np.median(differences)/2)+1)
    if samples>len(t):
        raise ValueError('Smoothing span exceeds the continuous input run')
    half=samples//2
    centered=y-y.mean(axis=0,keepdims=True)
    padded=np.pad(centered,[(half,half)]+[(0,0)]*(y.ndim-1),mode='reflect')
    integral=np.concatenate([np.zeros_like(padded[:1]),np.cumsum(padded,axis=0)],axis=0)
    return (integral[samples:]-integral[:-samples])/samples

"""Sandbox global ownership of frozen parents and already-local split children.

No image/signal detection, filter changes, injected truth or patient counts.
Global means all candidates in ONE wall. Cross-wall event pairing is separate.
"""
from copy import deepcopy
from itertools import combinations
import numpy as np


def _runs(mask):
    return np.flatnonzero(np.diff(np.r_[False,mask,False])).reshape(-1,2)


def build_entities(report,proposals,time_s,valid):
    t=np.asarray(time_s,float);m=np.asarray(valid,bool)
    if m.ndim!=2 or len(t)!=len(m) or len(t)<3 or np.any(np.diff(t)<=0):
        raise ValueError('Expected native time x section validity for one wall')
    epochs={c:_runs(m[:,c]) for c in range(m.shape[1])}
    def phase_node(col,p):
        index=int(np.argmin(abs(t-p['peak_s'])))
        epoch=next(((int(a),int(b)) for a,b in epochs[col] if a<=index<b),None)
        return dict(sign=int(p['sign']),peak_s=float(p['peak_s']),
            start_s=float(p['observed_start_s']),end_s=float(p['observed_end_s']),epoch=epoch)
    fragments={f['fragment_id']:f for f in report['fragments']}
    parents={e['event_id']:e for e in report['events']}
    entities={};parent_to_base={}
    for group in report['proposed_events']:
        eid='base:'+group['proposal_id'];profile={};arrival={}
        members=[parents[k] for k in group['fragment_ids']]
        for fid in group['fragment_ids']:
            f=fragments[fid];parent_to_base[fid]=eid
            for p in f['local_phase_support']:
                c=int(p['section']);profile.setdefault(c,[]).append(phase_node(c,p))
            arrival.update(zip(f['sections'],f['arrival_time_s']))
        for c in profile:
            unique={(p['sign'],p['peak_s']):p for p in profile[c]}
            profile[c]=sorted(unique.values(),key=lambda p:p['peak_s'])
        canonical=max(members,key=lambda e:(e['evidence_kind']=='paired_phase',len(e['sections'])))
        entities[eid]=dict(entity_id=eid,source_kind='existing',source_parents=list(group['fragment_ids']),
            complete=all(len(ps)==2 for ps in profile.values()),profile=profile,arrival=arrival,
            direction=canonical['classification'] if canonical['classification'] in ('C2F','F2C') else None,
            canonical_measurement=deepcopy(canonical),original_measurements=deepcopy(members),
            phase_ridge_provenance=[dict(parent_id=e['event_id'],phase_ridge_ids=e['phase_ridge_ids']) for e in members])
    splits=[]
    for proposal in proposals:
        if proposal['split_status']!='split_two':
            continue
        children=[]
        for child in (proposal['child_1'],proposal['child_2']):
            eid='child:'+child['event_id'];profile={}
            for row in child['supporting_phase_evidence']:
                c=int(row['section']);profile[c]=[phase_node(c,p) for p in row['phases']]
            entities[eid]=dict(entity_id=eid,source_kind='child',source_parents=[proposal['parent_candidate_id']],
                complete=True,profile=profile,arrival=dict(zip(child['sections'],child['arrival_time_s'])),
                direction=child['direction'],canonical_measurement=deepcopy(child),original_measurements=[],
                phase_ridge_provenance=[dict(parent_id=proposal['parent_candidate_id'],
                    source='parent_local_auxiliary',phase_ridge_ids=child['phase_ridge_ids'])])
            children.append(eid)
        splits.append(dict(parent_id=proposal['parent_candidate_id'],base_id=parent_to_base[proposal['parent_candidate_id']],
                           children=children))
    return entities,splits


def compare_identity(a,b,*,sample_dt_s,measurement_span_s):
    """Prioritized evidence, not a scalar score or fixed global-time radius.

    Existing 3-section connector support is reused. Both signs/sequence,
    physical continuity, local arrival and peak trajectories must agree.
    Uncomparable/partial evidence is retained rather than forcibly merged.
    """
    shared=sorted(set(a['profile'])&set(b['profile']))
    tolerance=measurement_span_s+sample_dt_s
    evidence=dict(shared_sections=shared,tolerance_s=tolerance,matched_sections=[],
                  exact_phase_nodes=0,phase_sequence_conflict=False,
                  direction_conflict=bool(a['direction'] and b['direction'] and a['direction']!=b['direction']))
    if not shared:
        return dict(relation='unrelated',priority=0,reason='no shared native support',**evidence)
    paired=a['complete'] and b['complete']
    exact=0;matched=[];near=[];contradictions=[]
    for c in shared:
        left,right=a['profile'][c],b['profile'][c]
        signs_a=[p['sign'] for p in left];signs_b=[p['sign'] for p in right]
        paired_here=len(left)==2 and len(right)==2
        if paired_here and signs_a!=signs_b:
            evidence['phase_sequence_conflict']=True
            continue
        pairs=[]
        for p in left:
            options=[q for q in right if q['sign']==p['sign']]
            if len(options)==1:
                pairs.append((p,options[0]))
        if not pairs:
            continue
        distances=[abs(p['peak_s']-q['peak_s']) for p,q in pairs]
        if min(distances)<=tolerance:
            near.append(c)
        epoch_ok=all(p['epoch'] is not None and p['epoch']==q['epoch'] for p,q in pairs)
        bounds_ok=all(q['start_s']-sample_dt_s<=p['peak_s']<=q['end_s']+sample_dt_s and
                      p['start_s']-sample_dt_s<=q['peak_s']<=p['end_s']+sample_dt_s for p,q in pairs)
        peaks_ok=max(distances)<=tolerance
        arrival_ok=not paired_here or abs(a['arrival'][c]-b['arrival'][c])<=tolerance
        if epoch_ok and bounds_ok and peaks_ok and arrival_ok:
            matched.append(c)
            exact+=sum(p['peak_s']==q['peak_s'] for p,q in pairs)
        elif min(distances)<=tolerance:
            contradictions.append(c)
    evidence.update(matched_sections=matched,exact_phase_nodes=exact)
    if evidence['phase_sequence_conflict']:
        return dict(relation='distinct',priority=0,reason='different ordered phase sequences',**evidence)
    blocks=np.split(np.asarray(matched,int),np.flatnonzero(np.diff(matched)!=1)+1)
    enough=max((len(x) for x in blocks),default=0)>=3
    if enough and not contradictions and len(matched)==len(shared):
        relation='duplicate' if paired else 'partial_duplicate'
        priority=3 if paired and exact==2*len(shared) else 2 if paired else 1
        return dict(relation=relation,priority=priority,reason='same local phase and arrival structure',**evidence)
    if near:
        return dict(relation='ambiguous',priority=0,reason='partial or conflicting local phase support',**evidence)
    return dict(relation='distinct',priority=0,reason='separate local phase timing',**evidence)


def _rank(e):
    # Complete evidence first, then larger native support; existing evidence
    # wins ties. A smaller local child cannot overwrite a wider complete parent.
    return (e['complete'],len(e['profile']),
            e['source_kind']=='existing',e['entity_id'])


def reconcile(report,proposals,time_s,valid,*,measurement_span_s):
    entities,splits=build_entities(report,proposals,time_s,valid)
    dt=float(np.median(np.diff(time_s)))
    relations={}
    def compare(x,y):
        key=tuple(sorted((x,y)))
        if key not in relations:
            relations[key]=compare_identity(entities[x],entities[y],sample_dt_s=dt,
                                            measurement_span_s=measurement_span_s)
        return relations[key]
    def duplicate(x,y):
        return compare(x,y)['relation'] in ('duplicate','partial_duplicate')
    bases=[k for k,e in entities.items() if e['source_kind']=='existing']
    base_ambiguity={}
    for x,y in combinations(bases,2):
        if compare(x,y)['relation']=='ambiguous':
            for k,other in ((x,y),(y,x)):
                base_ambiguity.setdefault(k,dict(reason='conflicting original ownership evidence',possible_owners=[]))['possible_owners'].append(other)
    for k in bases:
        choices=[p for p in bases if p!=k and entities[p]['complete'] and duplicate(k,p)]
        if any(not duplicate(a,b) for a,b in combinations(choices,2)):
            previous=base_ambiguity.get(k,{}).get('possible_owners',[])
            base_ambiguity[k]=dict(reason='original evidence matches conflicting complete events',possible_owners=sorted(set(previous+choices)))
    # Reconcile original evidence first. No child can serve as a transitive
    # bridge that merges otherwise conflicting original event identities.
    base_clusters={k:[k] for k in bases};base_owner={k:k for k in bases}
    for x,y in combinations(sorted(bases,key=lambda k:_rank(entities[k]),reverse=True),2):
        cx,cy=base_owner[x],base_owner[y]
        if cx==cy or x in base_ambiguity or y in base_ambiguity or not duplicate(x,y):
            continue
        union=base_clusters[cx]+base_clusters[cy]
        anchor=max(union,key=lambda k:_rank(entities[k]))
        if not all(k==anchor or duplicate(anchor,k) for k in union):
            continue
        if any(compare(p,q)['relation'] in ('ambiguous','distinct') for p,q in combinations(union,2)):
            continue
        base_clusters.pop(cx);base_clusters.pop(cy);base_clusters[anchor]=union
        for k in union:base_owner[k]=anchor
    owners={};uncertain={};attachments={k:[] for k in base_clusters}
    for k,e in entities.items():
        if e['source_kind']!='child':continue
        definite=[];possible=[]
        for anchor,members in base_clusters.items():
            relation=compare(k,anchor)
            if relation['relation'] in ('duplicate','partial_duplicate'):
                definite.append((anchor,relation['priority']))
            elif relation['relation']=='ambiguous':
                possible.append(anchor)
        highest=max((priority for _,priority in definite),default=0)
        strongest=[anchor for anchor,priority in definite if priority==highest]
        # Complete/exact evidence takes precedence over incomplete secondary
        # overlap. A partial match alone cannot resolve competing owners.
        if len(strongest)==1 and (highest>=2 or not any(p!=strongest[0] for p in possible)):
            owners[k]=strongest[0]
        elif definite or possible:
            uncertain[k]=dict(reason='multiple or incomplete existing ownership',
                              possible_owners=sorted(set([a for a,_ in definite]+possible)))
    must_separate={frozenset(s['children']) for s in splits}
    viable=[];actions=[]
    for split in splits:
        a,b=split['children']
        if a in uncertain or b in uncertain or (a in owners and b in owners and owners[a]==owners[b]):
            actions.append(dict(**split,status='ambiguous',reason='conflicting child ownership',child_owners=None))
        else:viable.append(split)
    unmatched=sorted({c for s in viable for c in s['children'] if c not in owners},
                     key=lambda k:_rank(entities[k]),reverse=True)
    new_clusters={};new_owner={}
    for child in unmatched:
        candidates=[anchor for anchor,members in new_clusters.items()
            if duplicate(child,anchor) and all(frozenset((child,k)) not in must_separate for k in members)
            and not any(compare(child,k)['relation'] in ('ambiguous','distinct') for k in members)]
        possible=[anchor for anchor in new_clusters if compare(child,anchor)['relation']=='ambiguous']
        if len(candidates)==1 and not possible:
            anchor=candidates[0];new_clusters[anchor].append(child);new_owner[child]=anchor
        elif candidates or possible:
            uncertain[child]=dict(reason='conflicting new-child ownership',possible_owners=sorted(set(candidates+possible)))
        else:
            new_clusters[child]=[child];new_owner[child]=child
    accepted=[]
    for split in viable:
        a,b=split['children']
        if a in uncertain or b in uncertain:
            actions.append(dict(**split,status='ambiguous',reason='new-child identity ambiguity',child_owners=None));continue
        assigned=[owners[c] if c in owners else new_owner[c] for c in (a,b)]
        if assigned[0]==assigned[1]:
            actions.append(dict(**split,status='ambiguous',reason='two children cannot share one identity',child_owners=None));continue
        action=dict(**split,status='reuse_existing' if all(c in owners for c in (a,b)) else 'accept_split',
                    reason='one identity per supported activity',child_owners=assigned)
        actions.append(action);accepted.append(action)
    # Resolve transaction dependencies monotonically: a rejected split cannot
    # erase an existing group or act as the sole bridge for another split.
    while True:
        active_children={c for a in accepted for c in a['children']}
        referenced={owner for a in accepted for owner in a['child_owners']}
        split_parents={a['parent_id'] for a in accepted}
        retired=set()
        for anchor,members in base_clusters.items():
            source_parents={p for k in members for p in entities[k]['source_parents']}
            complete_parents={m['event_id'] for k in members for m in entities[k]['original_measurements']
                              if m['evidence_kind']=='paired_phase'}
            # A remaining unpaired fragment is evidence, not an independently
            # complete event that can lock a decomposed container forever.
            # Preserve it explicitly as unresolved, never silently discard it.
            if (source_parents&split_parents and complete_parents<=split_parents and anchor not in referenced):
                retired.add(anchor)
        reject=set()
        for a in accepted:
            source=base_owner[a['base_id']]
            if source not in a['child_owners'] and source not in retired:
                reject.add(a['parent_id'])
                a['reason']='source group is still independently owned; cannot add two more identities'
        for anchor,members in new_clusters.items():
            active=[c for c in members if c in active_children]
            if not active:continue
            canonical=max(active,key=lambda k:_rank(entities[k]))
            if any(c!=canonical and not duplicate(c,canonical) for c in active):
                for a in accepted:
                    if anchor in a['child_owners']:
                        reject.add(a['parent_id']);a['reason']='new identity depends on rejected evidence bridge'
        if not reject:break
        for a in accepted:
            if a['parent_id'] in reject:a['status']='ambiguous';a['child_owners']=None
        accepted=[a for a in accepted if a['parent_id'] not in reject]
    finals=[];source_to_final={}
    def emit(anchor,members,kind):
        canonical=max(members,key=lambda k:_rank(entities[k]));e=entities[canonical]
        eid=f'event_proposal_{len(finals)+1:03d}'
        source_parents=sorted({p for k in members for p in entities[k]['source_parents']})
        finals.append(dict(event_proposal_id=eid,ownership_status='merged_evidence' if len(members)>1 else kind,
            canonical_source_entity_id=canonical,source_entity_ids=sorted(members),source_parent_ids=source_parents,
            from_split=any(entities[k]['source_kind']=='child' for k in members),
            supporting_sections=sorted(e['profile']),arrival_time_s=[e['arrival'][c] for c in sorted(e['profile'])],
            direction=e['direction'],canonical_measurement=deepcopy(e['canonical_measurement']),
            preserved_original_measurements=[deepcopy(m) for k in members for m in entities[k]['original_measurements']],
            phase_ridge_provenance=[deepcopy(p) for k in members for p in entities[k]['phase_ridge_provenance']],
            ownership_conflicts=[],event_count=None,event_frequency=None,reviewed=False))
        for k in members:source_to_final[k]=eid
    for anchor,members in sorted(base_clusters.items()):
        if anchor in retired:continue
        children=[c for c in active_children if owners.get(c)==anchor]
        emit(anchor,members+sorted(children),'retained_existing')
    for anchor,members in sorted(new_clusters.items()):
        active=[c for c in members if c in active_children]
        if active:emit(anchor,active,'retained_new_child')
    for action in actions:
        action['final_event_ids']=[source_to_final.get(c) for c in action['children']] if action['status']!='ambiguous' else []
    ambiguity=[dict(source_entity_id=k,**v) for k,v in sorted({**base_ambiguity,**uncertain}.items())]
    for event in finals:
        event['ownership_conflicts']=[a['source_entity_id'] for a in ambiguity
            if a['source_entity_id'] in event['source_entity_ids'] or any(owner in event['source_entity_ids'] for owner in a['possible_owners'])]
        event['ownership_conflicts'] += ['split:'+a['parent_id'] for a in actions if a['status']=='ambiguous'
                                        and a['parent_id'] in event['source_parent_ids']]
        if event['ownership_conflicts']:event['ownership_status']='ambiguous_preserved_existing'
    return dict(event_proposals=finals,split_actions=actions,ambiguous_ownership=ambiguity,
        source_to_final=source_to_final,retired_parent_groups=sorted(retired),
        unresolved_retired_fragments=[dict(parent_candidate_id=m['event_id'],source_group=anchor,
            original_measurement=deepcopy(m),status='unassigned_original_fragment',
            reason='Container split; partial fragment has no independently complete identity')
            for anchor in sorted(retired) for k in base_clusters[anchor] for m in entities[k]['original_measurements']
            if m['event_id'] not in split_parents],
        source_evidence=deepcopy(entities),
        pairwise_evidence=[dict(source_a=x,source_b=y,**value) for (x,y),value in sorted(relations.items())
                           if value['relation'] not in ('unrelated','distinct')],
        matching_rules=dict(native_sample_dt_s=dt,measurement_span_s=measurement_span_s,
            timing_tolerance_s=measurement_span_s+dt,minimum_shared_adjacent_sections=3,
            priority=['exact ordered phase nodes','complete phase and arrival structure','unique partial phase ownership'],
            no_transitive_bridge=True),event_count=None,event_frequency=None)

"""Wang-inspired pointwise relative salience on unchanged radial maps.

The paper's magnitude is |curvature change|; here it is |filtered radial A|.
Min/max are fixed over the complete video and BOTH walls, not each candidate
or column. The paper does not specify this pooling scope. Cutoff=.6 and three
adjacent native supports reuse the published cutoff and current fit support.
"""
import numpy as np


def normalize_magnitude(filtered, valid):
    y = np.asarray(filtered, float); m = np.asarray(valid, bool)
    if y.shape != m.shape or y.ndim != 3 or y.shape[1] != 2:
        raise ValueError('Expected time x two walls x native sections with valid mask')
    supported = m & np.isfinite(y)
    magnitude = abs(y[supported]); normalized = np.full_like(y, np.nan)
    if not len(magnitude):
        return normalized, dict(status='no_filtered_support',minimum=None,maximum=None,
            physical_cutoff=None,cutoff=.6,normalization_scope='whole_video_both_walls')
    low = float(magnitude.min()); high = float(magnitude.max())
    normalized[supported] = (magnitude-low)/(high-low) if high > low else 0.
    return normalized, dict(status='normalized' if high>low else 'constant_magnitude',
        minimum=low,maximum=high,physical_cutoff=low+.6*(high-low),cutoff=.6,
        normalization_scope='whole_video_both_walls',valid_filtered_samples=int(supported.sum()),
        salient_samples=int((normalized[supported]>.6).sum()))


def score_salience(event, source_evidence, normalized, valid, time_s):
    entity = source_evidence[event['canonical_source_entity_id']]
    t = np.asarray(time_s, float); y = np.asarray(normalized, float); m = np.asarray(valid, bool)
    if y.shape != m.shape or y.ndim != 2 or y.shape[0] != len(t):
        raise ValueError('Expected one native wall with matching time and validity')
    ids = sorted(int(c) for c in entity['profile']); supported=[]; per_section=[]
    for col in ids:
        phases = entity['profile'].get(str(col),entity['profile'].get(col))
        lo = min(p['start_s'] for p in phases); hi = max(p['end_s'] for p in phases)
        a = int(np.searchsorted(t,lo-1e-8)); b = int(np.searchsorted(t,hi+1e-8,side='right'))
        good = b>a and m[a:b,col].all() and np.isfinite(y[a:b,col]).all()
        peak = float(y[a:b,col].max()) if good else None
        samples = int((y[a:b,col]>.6).sum()) if good else 0
        if good and peak>.6:supported.append(col)
        per_section.append(dict(section=col,normalized_peak=peak,salient_samples=samples,
                                phase_support_complete=bool(good)))
    blocks = [b.tolist() for b in np.split(np.asarray(supported,int),
              np.flatnonzero(np.diff(supported)!=1)+1) if len(b)>=3]
    retained = sorted(c for block in blocks for c in block)
    return dict(event_proposal_id=event['event_proposal_id'],
        canonical_source=event['canonical_source_entity_id'],cutoff=.6,
        decision='salient_support' if retained else 'insufficient_salient_support',
        original_sections=ids,salient_sections=supported,retained_sections=retained,
        native_contiguous_blocks=blocks,per_section=per_section,
        direction=event['direction'],direction_source='unchanged_original_proposal_not_refit_on_subset',
        ownership_status=event['ownership_status'],event_count=None,event_frequency=None)

"""Sandbox: retain observable boundary peaks and propose fragment ownership.

Default detector and formal event interfaces are unchanged. Proposed groups
are not reviewed waves, and their number is not physiological frequency.
"""
from copy import deepcopy
from unittest.mock import patch
import numpy as np
from uterine_wave import radial_events as baseline


def observed_lobes(y, valid, t, threshold):
    filtered = np.full_like(y, np.nan)
    columns = [[] for _ in range(y.shape[1])]
    unresolved = []
    minimum = max(3, int(np.ceil(12/np.median(np.diff(t)))))
    for col in range(y.shape[1]):
        for run_id, (begin, end) in enumerate(baseline._runs(valid[:, col])):
            if end-begin < minimum:
                continue
            signal = baseline.band_limited_signal(y[begin:end, col], t[begin:end])
            filtered[begin:end, col] = signal
            edges = np.r_[0, np.flatnonzero(np.diff(signal >= 0))+1, len(signal)]
            for sequence, (a, b) in enumerate(zip(edges[:-1], edges[1:])):
                peak = int(a+np.argmax(abs(signal[a:b])))
                amplitude = float(abs(signal[peak]))
                left, right = bool(a == 0), bool(b == len(signal))
                if amplitude <= max(float(threshold[col]), 1e-12):
                    continue
                if (left or right) and peak in (a, b-1):
                    unresolved.append(dict(column=col, run_id=run_id,
                        observed_start_s=float(t[begin+a]), observed_end_s=float(t[begin+b-1]),
                        peak_observed=False, left_censored=left, right_censored=right))
                    continue
                columns[col].append(dict(column=col, run_id=run_id, sequence=sequence,
                    sign=1 if signal[peak] > 0 else -1, peak_index=int(begin+peak),
                    peak_time_s=float(t[begin+peak]), amplitude=amplitude,
                    first=int(begin+a), last=int(begin+b-1),
                    start_s=float(t[begin+a]), end_s=float(t[begin+b-1]),
                    left_censored=left, right_censored=right, peak_observed=True))
    return filtered, columns, unresolved


def propose_groups(report):
    """Unique disjoint complementary ownership proposals, no automatic review.

    Only a whole single-phase candidate can attach, never silently assign a
    subset and lose its remaining support. Opposite temporal roles, ambiguous
    destinations and overlapping local phase nodes remain separate evidence.
    """
    events = report['events']
    paired = [e for e in events if e['evidence_kind'] == 'paired_phase']
    mapping = {e['event_id']:e['event_id'] for e in events}
    attachments, unresolved = {}, []
    used_sections = {e['event_id']:set(e['sections']) for e in paired}
    for event in events:
        if event['evidence_kind'] != 'single_phase':
            continue
        ridge = event['phase_ridge_ids'][0]
        choices = []
        for edge in report['alternative_phase_pairs']:
            if edge['selected'] or ridge not in edge['phase_ridge_ids']:
                continue
            if edge['sections'] != event['sections']:
                continue
            other = next(k for k in edge['phase_ridge_ids'] if k != ridge)
            for parent in paired:
                if (other in parent['phase_ridge_ids'] and
                    not set(edge['sections'])&set(parent['sections']) and
                    edge['leading_polarity'] == parent['leading_polarity'] and
                    edge['classification'] == parent['classification'] == event['classification'] and
                    event['classification'] in ('C2F', 'F2C')):
                    choices.append((parent, edge))
        if len(choices) != 1:
            if choices:
                unresolved.append(dict(candidate_id=event['event_id'], reason='multiple_possible_parent_events',
                                       possible_parents=[p['event_id'] for p, _ in choices]))
            continue
        parent, edge = choices[0]

def anchor_to_existing_candidates(original, observed):
    """Use retained boundary evidence to repair existing proposals only.

    All original candidates remain traceable. Novel/unmatched boundary paths
    remain additional support, never automatically new independent events.
    Exact phase-node identity is used; no numerical match threshold is tuned.
    """
    def tokens(report, event):
        ridges = {r['ridge_id']:r for r in report['phase_ridges']}
        return {(ridges[k]['sign'], col, time) for k in event['phase_ridge_ids']
                for col, time in zip(ridges[k]['sections'], ridges[k]['peak_time_s'])
                if col in event['sections']}
    observed_by_id = {e['event_id']:e for e in observed['events']}
    pieces_by_id = {p['fragment_id']:p for p in observed['fragments']}
    group_tokens = {}
    for group in observed['proposed_events']:
        combined = set()
        for fragment_id in group['fragment_ids']:
            source = observed_by_id[fragment_id]
            piece = pieces_by_id[fragment_id]
            combined.update(tokens(observed, dict(source, sections=piece['sections'],
                                                   phase_ridge_ids=piece['phase_ridge_ids'])))
        group_tokens[group['proposal_id']] = combined
    destinations, ambiguity = {}, []
    for event in original['events']:
        signature = tokens(original, event)
        choices = [key for key, support in group_tokens.items() if signature <= support]
        if len(choices) == 1:
            destinations[event['event_id']] = choices[0]
        else:
            destinations[event['event_id']] = None
            ambiguity.append(dict(candidate_id=event['event_id'], reason='no_unique_complete_phase_support',
                                  possible_groups=choices))
    conflicting = set()
    for key in group_tokens:
        directions = {event['classification'] for event in original['events']
                      if destinations[event['event_id']] == key
                      and event['classification'] in ('C2F', 'F2C')}
        if len(directions) > 1:
            conflicting.add(key)
            ambiguity.append(dict(observed_group=key, reason='opposing_original_directions'))
    groups = {}
    for event in original['events']:
        destination = destinations[event['event_id']]
        key = ('observed', destination) if destination is not None and destination not in conflicting else ('original', event['event_id'])
        groups.setdefault(key, []).append(event)
    output = []
    used_observed = set()
    observed_groups = {g['proposal_id']:g for g in observed['proposed_events']}
    for number, (key, events) in enumerate(groups.items(), 1):
        if key[0] == 'observed':
            used_observed.add(key[1])
        output.append(dict(proposal_id=f'activity_proposal_{number:03d}',
            source_candidate_ids=[e['event_id'] for e in events],
            observed_fragment_ids=observed_groups[key[1]]['fragment_ids'] if key[0] == 'observed' else [],
            observed_support_group=key[1] if key[0] == 'observed' else None,
            direction_candidate=any(e['classification'] in ('C2F', 'F2C') for e in events),
            ownership_status='proposed_shared_identity' if len(events) > 1 else 'single_existing_candidate',
            identity_reviewed=False))
    return dict(existing_candidate_groups=output,
        additional_support_groups=[g for g in observed['proposed_events'] if g['proposal_id'] not in used_observed],
        mapping_ambiguities=ambiguity,
        existing_direction_group_proposals=sum(g['direction_candidate'] for g in output),
        formal_event_count=None, formal_event_frequency_cpm=None,
        interpretation='Support-assisted ownership proposals only; no new independent waves or reviewed identities')

def compare_walls(a,b,span,dt):
    if a['wall']==b['wall']:raise ValueError('Cross-wall comparison requires different walls')
    shared=sorted(set(a['sections'])&set(b['sections']));tolerance=span+dt
    matched=[];near=[];conflict=[]
    for c in shared:
        left,right=a['profile'][c],b['profile'][c]
        same_sequence=[p['sign'] for p in left]==[p['sign'] for p in right]
        pairs=[(p,q) for p in left for q in right if p['sign']==q['sign']]
        peak_near=any(abs(p['peak_s']-q['peak_s'])<=tolerance for p,q in pairs)
        comparable_arrival=a['arrival_marker']==b['arrival_marker']
        arrival_near=comparable_arrival and abs(a['arrival'][c]-b['arrival'][c])<=tolerance
        if peak_near or arrival_near:near.append(c)
        if not same_sequence or not comparable_arrival:
            if peak_near or arrival_near:conflict.append(c)
            continue
        # Each wall has its own continuity bounds. Their run indices need not
        # equal: they describe different tissue, not the same material point.
        valid=(all(p.get('epoch') is not None and q.get('epoch') is not None for p,q in pairs) and
            all(abs(p['peak_s']-q['peak_s'])<=tolerance and
                q['start_s']-dt<=p['peak_s']<=q['end_s']+dt and
                p['start_s']-dt<=q['peak_s']<=p['end_s']+dt for p,q in pairs) and arrival_near)
        if valid:matched.append(c)
        elif peak_near or arrival_near:conflict.append(c)
    direction_compatible=(a['direction']==b['direction'])
    relation='shared_identity_supported' if (longest_adjacent(matched)>=3 and
        len(matched)==len(shared) and not conflict and direction_compatible) else (
        'unresolved' if near else 'no_shared_identity_evidence')
    return dict(node_a=a['node_id'],node_b=b['node_id'],relation=relation,
        shared_sections=shared,matched_sections=matched,near_sections=near,
        phase_or_marker_conflict_sections=conflict,directions_compatible=direction_compatible,
        tolerance_s=tolerance,reason=('phase order, peaks, local arrival and direction agree' if relation=='shared_identity_supported'
            else 'partial/conflicting cross-wall evidence' if relation=='unresolved'
            else 'insufficient corresponding native phase/arrival evidence'))

        elif edge['relation']=='unresolved':uncertain[a].append(b);uncertain[b].append(a)

    pairs={tuple(sorted((a,bs[0]))) for a,bs in choices.items() if len(bs)==1 and

            unresolved_related_nodes=unresolved,evidence_start_s=min(p['start_s'] for p in phases),

def _interval_union(begin, end, supported):
    intervals = []
    for a, b in zip(begin[supported], end[supported]):
        a = float(a); b = float(b)
        if intervals and a <= intervals[-1][1] + 1e-9:
            intervals[-1][1] = max(intervals[-1][1], b)
        else:
            intervals.append([a, b])
    return intervals


def _minimum_run_mask(raw_v, time_s, min_run_s):
    """Mirror filtered_runs() continuous-support eligibility, without filtering A.

    raw_v: time x wall x section boolean support.
    A sample becomes detector-eligible only if it belongs to a continuous
    per-(wall,section) run long enough for the current detector.
    """
    raw_v = np.asarray(raw_v, bool)
    t = np.asarray(time_s, float)
    if raw_v.ndim != 3 or raw_v.shape[0] != len(t):
        raise ValueError('raw_v must be time x wall x section and match time_s')
    if len(t) < 2 or not np.isfinite(t).all() or np.any(np.diff(t) <= 0):
        raise ValueError('time_s must contain at least two finite increasing samples')
    if min_run_s is None:
        return raw_v.copy(), None
    if not np.isfinite(min_run_s) or min_run_s <= 0:
        raise ValueError('min_run_s must be positive or None')

    minimum = max(3, int(np.ceil(float(min_run_s) / np.median(np.diff(t)))))
    eligible = np.zeros_like(raw_v)
    for wall in range(raw_v.shape[1]):
        for section in range(raw_v.shape[2]):
            runs = np.flatnonzero(
                np.diff(np.r_[False, raw_v[:, wall, section], False])
            ).reshape(-1, 2)
            for first, last in runs:
                if last - first >= minimum:
                    eligible[first:last, wall, section] = True
    return eligible, minimum


def observation_union(maps, *, min_run_s=12.0):
    """Detector-aligned observation-time denominator.

    Frequency exposure is the union of measurement intervals for which at
    least one wall has >=3 adjacent native sections that belong to a
    continuous per-section run satisfying the detector's minimum support.

    This is NOT a claim that 12 s is sufficient to estimate the whole
    0.5--5 cpm band. It only mirrors the current detector's minimum
    continuous-support rule so numerator and denominator use the same domain.
    """
    raw_v = np.asarray(maps['valid_mask'], bool) & np.isfinite(maps['A'])
    begin = np.asarray(maps['interval_start_s'], float)
    end = np.asarray(maps['interval_end_s'], float)
    t = np.asarray(maps.get('interval_center_s', 0.5 * (begin + end)), float)
    if (raw_v.ndim != 3 or raw_v.shape[1] != 2 or len(raw_v) != len(begin) or
            end.shape != begin.shape or t.shape != begin.shape or
            not np.isfinite(begin).all() or not np.isfinite(end).all() or
            np.any(end <= begin)):
        raise ValueError('Expected physical radial interval maps')

    v, minimum = _minimum_run_mask(raw_v, t, min_run_s)

    def spatially_observable(mask):
        if mask.shape[2] < 3:
            return np.zeros(len(mask), bool)
        return (mask[:, :, :-2] & mask[:, :, 1:-1] & mask[:, :, 2:]).any((1, 2))

    raw_supported = spatially_observable(raw_v)
    supported = spatially_observable(v)
    raw_intervals = _interval_union(begin, end, raw_supported)
    intervals = _interval_union(begin, end, supported)
    raw_seconds = float(sum(b-a for a, b in raw_intervals))
    seconds = float(sum(b-a for a, b in intervals))

    return dict(
        seconds=seconds,
        intervals_s=intervals,
        raw_seconds=raw_seconds,
        raw_observation_seconds=raw_seconds,
        filtered_observation_seconds=seconds,
        filtered_observation_fraction=(seconds/raw_seconds if raw_seconds > 0 else None),
        raw_intervals_s=raw_intervals,
        filtered_over_raw_observation_fraction=(seconds/raw_seconds if raw_seconds > 0 else None),
        min_run_s=None if min_run_s is None else float(min_run_s),
        minimum_run_samples=None if minimum is None else int(minimum),
        rule=('union of measurement intervals with >=3 adjacent native sections in either wall, '
              'after per-section continuous-run eligibility aligned to the event detector'),
        coverage_scope='locally observable radial activity, not proof of full-cavity visibility',
    )

def _segments(rows):
    """Split one spatial block into chronological runs without crossing gaps."""
    rows = sorted(rows, key=lambda row: row["window_center_s"])
    times = np.asarray([row["window_center_s"] for row in rows], float)
    if len(times) == 1:
        return [rows]
    positive = np.diff(times)
    positive = positive[positive > 0]
    if not len(positive):
        raise ValueError("Repeated paired-window timestamps")
    step = float(np.median(positive))
    cuts = np.flatnonzero(np.diff(times) > 1.5 * step) + 1
    bounds = np.r_[0, cuts, len(rows)]
    return [rows[int(left):int(right)] for left, right in zip(bounds[:-1], bounds[1:])]


def _coordination(rows):
    x = np.asarray([row["anterior_ER"] for row in rows], float)
    y = np.asarray([row["posterior_ER"] for row in rows], float)
    if not np.isfinite(x).all() or not np.isfinite(y).all():
        raise ValueError("Paired ER values must be finite")
    mse = float(np.mean((x - y) ** 2))
    cc = (
        float(np.corrcoef(x, y)[0, 1])
        if len(rows) >= 3 and np.std(x) > 1e-12 and np.std(y) > 1e-12
        else None
    )
    return mse, cc


def _decompose(ant, post, observed_mse):
    """Decompose observed ER-MSE into bias, scale and time-shape terms."""
    ant = np.asarray(ant, float)
    post = np.asarray(post, float)
    mean_ant = float(ant.mean())
    mean_post = float(post.mean())
    sd_ant = float(ant.std(ddof=0))
    sd_post = float(post.std(ddof=0))
    mean_bias_sq = float((mean_ant - mean_post) ** 2)
    scale_difference_sq = float((sd_ant - sd_post) ** 2)
    if len(ant) >= 3 and sd_ant > 1e-12 and sd_post > 1e-12:
        cc = float(np.corrcoef(ant, post)[0, 1])
        shape_term = float(2 * sd_ant * sd_post * (1 - cc))
        standardized_mse = float(
            np.mean(
                (
                    (ant - mean_ant) / sd_ant
                    - (post - mean_post) / sd_post
                )
                ** 2
            )
        )
    else:
        shape_term = float(observed_mse - mean_bias_sq - scale_difference_sq)
        standardized_mse = None
    return dict(
        record_ER_mean_anterior=mean_ant,
        record_ER_mean_posterior=mean_post,
        record_ER_sd_anterior=sd_ant,
        record_ER_sd_posterior=sd_post,
        record_mean_bias_sq=mean_bias_sq,
        record_sd_scale_sq=scale_difference_sq,
        record_time_shape_term=shape_term,
        record_MSE_z=standardized_mse,
    )

"""Existing CUDA LK and grayscale QC, without machine-specific imports."""
import cv2
import numpy as np

_FLOWS = {}


def local_contrast(gray, sigma=5.):
    source = gray.astype(np.float32)
    mean = cv2.GaussianBlur(source, (0, 0), sigma)
    square = cv2.GaussianBlur(source*source, (0, 0), sigma)
    std = np.sqrt(np.maximum(square-mean*mean, 0))
    mapped = 128+35*(source-mean)/(std+5)
    return np.uint8(np.where(gray > 12, np.clip(np.rint(mapped), 0, 255), 0))


def patch(image, point, radius):
    x, y = point
    h, w = image.shape
    if not np.isfinite(point).all() or min(x,y) < radius+1 or x >= w-radius-1 or y >= h-radius-1:
        return None
    return cv2.getRectSubPix(image, (2*radius+1, 2*radius+1), (float(x), float(y)))


def flow(a, b, p, window, initial=None):
    p = np.asarray(p, np.float32).reshape(1, -1, 2)
    if initial is not None:
        initial = np.asarray(initial, np.float32)
        if initial.shape != p.reshape(-1, 2).shape or not np.isfinite(initial).all():
            raise ValueError("Initial target must be finite Nx2")
    key = (window, initial is not None)
    if key not in _FLOWS:
        if cv2.cuda.getCudaEnabledDeviceCount() < 1:
            raise RuntimeError("CUDA OpenCV with cudaoptflow is required; no CPU fallback is used")
        cv2.cuda.setDevice(0)
        factory = getattr(cv2, 'cuda_SparsePyrLKOpticalFlow', None)
        _FLOWS[key] = (factory.create((window, window), 3, 30, initial is not None)
                      if factory is not None else
                      cv2.cuda.SparsePyrLKOpticalFlow_create((window, window), 3, 30, initial is not None))
    def upload(x):
        gpu = cv2.cuda_GpuMat()
        gpu.upload(np.ascontiguousarray(x))
        return gpu
    target = upload(initial.reshape(1, -1, 2)) if initial is not None else None
    q, status, err = _FLOWS[key].calc(upload(a), upload(b), upload(p), target)
    return q.download().reshape(-1, 1, 2), status.download().reshape(-1, 1), None


def match(a,b,qa,qb,p,window,initial=None,*,max_fb_px=.75,qc_scale=1.,qc_window=None,return_diagnostics=False):
    found,ok,_=flow(a,b,p,window,initial)
    points=found[:,0];back,bok,_=flow(b,a,points,window,p if initial is not None else None)
    fb=np.linalg.norm(back[:,0]-p,axis=1)
    good=ok.ravel().astype(bool)&bok.ravel().astype(bool)&np.isfinite(points).all(1)&(fb<=max_fb_px)
    # Pixel-center convention of spatial downsampling; localization stays native.
    qp,qq=(p,points) if qc_scale==1 else ((p+.5)/qc_scale-.5,(points+.5)/qc_scale-.5)
    radius=int(round((window//2)/qc_scale)) if qc_window is None else qc_window//2
    score=np.full(len(p),-1.);reason=np.full(len(p),'fb_or_flow_rejected',dtype='U24')
    for j in np.flatnonzero(good):
        x,y=patch(qa,qp[j],radius),patch(qb,qq[j],radius)
        if x is None or y is None:good[j]=False;reason[j]='patch_outside';continue
        if min(x.std(),y.std())<2:good[j]=False;reason[j]='low_texture';continue
        x=x.astype(float).ravel();y=y.astype(float).ravel();x-=x.mean();y-=y.mean();den=np.linalg.norm(x)*np.linalg.norm(y)
        score[j]=float(x@y/den) if den>1e-10 else -1.
        good[j]=score[j]>=.75;reason[j]='accepted' if good[j] else 'ncc_rejected'
    result = (points,good,score,fb,reason)
    if return_diagnostics:
        return (*result, dict(forward_status=ok.ravel().astype(bool),
                              backward_status=bok.ravel().astype(bool)))
    return result

"""Amplitude-related summaries for complete radial-strain time blocks."""
import numpy as np


def band_limited_signal(values, time_s, band_cpm=(.5, 5.)):
    """Return a zero-phase FFT band pass of one complete time block.

    ``values`` may have any trailing spatial dimensions.  The result has those
    trailing dimensions.  This is an interval-strain variability measure, not
    a single-event peak amplitude.  Missing samples are not filled.
    """
    values = np.asarray(values, float)
    time_s = np.asarray(time_s, float)
    if values.ndim < 1 or values.shape[0] != len(time_s) or len(time_s) < 3:
        raise ValueError('Expected time-first values with at least three samples')
    if not np.isfinite(values).all() or not np.isfinite(time_s).all():
        raise ValueError('Band-limited SD requires a complete finite block')
    dt = np.diff(time_s)
    if np.any(dt <= 0) or not np.allclose(dt, np.median(dt), rtol=1e-5, atol=1e-9):
        raise ValueError('FFT amplitude requires uniform real timestamps')
    if not 0 < band_cpm[0] < band_cpm[1]:
        raise ValueError('Invalid temporal frequency band')
    centered = values - values.mean(axis=0, keepdims=True)
    spectrum = np.fft.rfft(centered, axis=0)
    frequencies = np.fft.rfftfreq(len(time_s), np.median(dt))
    keep = (frequencies >= band_cpm[0]/60) & (frequencies <= band_cpm[1]/60)
    spectrum[~keep] = 0
    return np.fft.irfft(spectrum, n=len(time_s), axis=0)


def band_limited_sd(values, time_s, band_cpm=(.5, 5.)):
    """Return per-column SD after band limiting a complete time block."""
    return np.std(band_limited_signal(values, time_s, band_cpm), axis=0)


def summarize_interval_strain(values, time_s, band_cpm=(.5, 5.)):
    """Raw and physiological-band SD for one complete interval-strain block."""
    values = np.asarray(values, float)
    band_sd = band_limited_sd(values, time_s, band_cpm)
    raw_sd = np.std(values, axis=0)
    resolution = 60/(len(time_s)*np.median(np.diff(np.asarray(time_s, float))))
    bins = np.fft.rfftfreq(len(time_s), np.median(np.diff(time_s)))
    positive_bins = int(((bins >= band_cpm[0]/60) & (bins <= band_cpm[1]/60)).sum())
    return dict(
        definition='band_limited_interval_radial_strain_SD',
        interpretation='radial_stretch_activity_amplitude',
        units='dimensionless',
        depends_on_measurement_interval_and_motion_rate=True,
        raw_SD_per_pair=raw_sd,
        raw_SD_mean=float(raw_sd.mean()),
        band_SD_per_pair=band_sd,
        band_SD_mean=float(band_sd.mean()),
        band_cpm=list(band_cpm),
        time_resolution_cpm=float(resolution),
        positive_frequency_bins=positive_bins,
        duration_s=float(time_s[-1]-time_s[0]),
    )

"""Signed interval deformation with explicit topology and continuity masks."""
import numpy as np

DEFAULT_PROPAGATION_INTERVAL_S = 2.0
SENSITIVITY_INTERVAL_S = .96


def validate_time(time_s, count, hop):
    t = np.asarray(time_s, float)
    if t.shape != (count,) or not np.isfinite(t).all() or np.any(np.diff(t) <= 0):
        raise ValueError("Expected finite, strictly increasing acquisition times")
    if not isinstance(hop, (int, np.integer)) or not 1 <= hop < count:
        raise ValueError("hop must be an integer between 1 and frame_count-1")
    return t


def interval_support(tracks, hop):
    """No invalid step, segment change or correction-epoch change may be crossed."""
    valid = np.asarray(tracks['target_valid'], bool).copy()
    if valid.ndim != 2:
        raise ValueError("target_valid must be time x point")
    validate_time(tracks['time_s'], len(valid), hop)
    if 'pose_valid' in tracks:
        pose_valid = np.asarray(tracks['pose_valid'], bool)
        if pose_valid.shape != (len(valid),):
            raise ValueError('pose_valid must have one entry per frame')
        valid &= pose_valid[:, None]
    step = np.asarray(tracks['step_valid'], bool).copy()
    segment = np.asarray(tracks['segment_id'])
    if step.shape != valid.shape or segment.shape != valid.shape:
        raise ValueError("Track validity and segment arrays must share a shape")
    epoch = np.asarray(tracks.get('pose_epoch', np.zeros(len(valid), int)))
    if epoch.shape != (len(valid),):
        raise ValueError("pose_epoch must have one entry per frame")
    step[1:] &= valid[1:] & valid[:-1]
    step[1:] &= segment[1:] == segment[:-1]
    step[1:] &= (epoch[1:] == epoch[:-1])[:, None]
    failures = np.vstack((np.zeros((1, valid.shape[1]), int), np.cumsum(~step[1:], axis=0)))
    return valid[hop:] & valid[:-hop] & (failures[hop:] - failures[:-hop] == 0)


def rate_A(points, grid, time_s, hop=8):
    """(L(t)-L(t-hop))/L(t-hop)/dt, positive for radial lengthening; s^-1."""
    points = np.asarray(points, float)
    t = validate_time(time_s, len(points), hop)
    p = points[:, grid['A_pair_ids']]
    lengths = np.linalg.norm(p[:, :, :, 1] - p[:, :, :, 0], axis=-1)
    result = np.full_like(lengths[hop:], np.nan)
    denominator = lengths[:-hop] * (t[hop:] - t[:-hop])[:, None, None]
    np.divide(lengths[hop:] - lengths[:-hop], denominator, out=result, where=denominator > 0)
    return result


def curvature(points, arc):
    """Signed curvature of a local 5-seed quadratic in initial arc coordinates."""
    points = np.asarray(points, float)
    arc = np.asarray(arc, float)
    if points.ndim != 3 or points.shape[2] != 2 or points.shape[1] != len(arc):
        raise ValueError("Expected time x spatial_point x xy and matching arc")
    if len(arc) < 5 or not np.isfinite(arc).all() or np.any(np.diff(arc) <= 0):
        raise ValueError("Curvature needs five distinct ordered spatial samples")
    out = np.full((len(points), len(arc) - 4), np.nan)
    for j in range(2, len(arc) - 2):
        s = arc[j-2:j+3] - arc[j]
        inverse = np.linalg.pinv(np.column_stack((np.ones(5), s, s*s)))
        coef = np.einsum('ij,tjk->tik', inverse, points[:, j-2:j+3])
        v, a = coef[:, 1], 2*coef[:, 2]
        denominator = np.linalg.norm(v, axis=1)**3
        numerator = v[:, 0]*a[:, 1] - v[:, 1]*a[:, 0]
        np.divide(numerator, denominator, out=out[:, j-2], where=denominator > 1e-20)
    return out


def rate_B(points, grid, time_s, hop=8):
    """Curvature change per second; (processed pixel * second)^-1."""
    t = validate_time(time_s, len(points), hop)
    values = []
    arcs = []
    for ids, arc in zip(grid['B_curve_ids'], grid['B_arc_positions']):
        kappa = curvature(np.asarray(points)[:, ids], arc)
        values.append((kappa[hop:] - kappa[:-hop]) / (t[hop:] - t[:-hop])[:, None])
        arcs.append(arc[2:-2])
    return np.stack(values, axis=1), np.asarray(arcs)


def compute_maps(tracks, grid, hop=8):
    """A IDs address A seeds, B IDs address B seeds; tracking order is [A, B]."""
    points = np.asarray(tracks['corrected'], float)
    count_a, count_b = len(grid['A_points']), len(grid['B_points'])
    if points.shape != (len(tracks['time_s']), count_a + count_b, 2):
        raise ValueError("Expected corrected trajectories in explicit [A_points, B_points] order")
    effective = dict(tracks)

    support = interval_support(effective, hop)

    support &= np.isfinite(points[hop:]).all(2) & np.isfinite(points[:-hop]).all(2)
    a = rate_A(points[:, :count_a], grid, tracks['time_s'], hop)

def compute_spacetime(tracks, grid, *, interval_s=DEFAULT_PROPAGATION_INTERVAL_S):

                hop=hop, nominal_interval_s=float(interval_s),

"""Measure reviewed propagation events on the existing radial maps.

Arrival annotations describe the same contraction/relaxation structure across
positions. They are not detected from individual colour bands or ER windows.
One event_id identifies one activity across walls; a reflection is a new event.
"""
import numpy as np


def measure_event(spacetime, event):
    """Fit arrival time = intercept + slope*s; speed = 1/slope.

    Required: event_id, wall (0/1), start_s, end_s, sections (zero based),
    arrival_time_s, reviewed. Three distinct adjacent sections are a numerical
    fitting requirement, not a published physiological minimum wave extent.
    Non-monotone arrival sequences remain complex, with no single speed.
    """
    t = np.asarray(spacetime['interval_center_s'], float)
    s = np.asarray(spacetime['s'], float)
    wall = event['wall']
    ids = np.asarray(event['sections'])
    arrival = np.asarray(event['arrival_time_s'], float)
    start, end = float(event['start_s']), float(event['end_s'])

def pair_wall_events(events, space):
    """Pair only explicitly reviewed shared event IDs; never sum both walls."""
    pairs = []
    for event_id in sorted({row['event_id'] for row in events}):
        rows = [row for row in events if row['event_id'] == event_id and
                row['status'] in ('reviewed_propagation', 'reviewed_complex_activity')]
        if len(rows) != 2 or {row['wall'] for row in rows} != {0, 1}:
            continue
        anterior, posterior = sorted(rows, key=lambda row: row['wall'])
        common = sorted(set(anterior['sections']) & set(posterior['sections']))
        if not common:
            continue
        # Only shared sampled positions; no spatial interpolation.
        ta = dict(zip(anterior['sections'], anterior['arrival_time_s']))
        tp = dict(zip(posterior['sections'], posterior['arrival_time_s']))
        lag = [tp[j]-ta[j] for j in common]
        pairs.append(dict(event_id=event_id, sections=common,
                          s=np.asarray(space)[common].tolist(),
                          directions_agree=anterior['direction'] == posterior['direction'],
                          posterior_minus_anterior_arrival_s=lag,
                          mean_arrival_difference_s=float(np.mean(lag))))
    return pairs

"""Local video decoding. Retain all decoded frames and source presentation times."""
from pathlib import Path
import numpy as np


def read_video(path, *, time_factor, coordinate_scale=.5):
    """time_factor=3 for a verified 3x speed-up; factor is never inferred from a name."""
    import cv2
    if time_factor <= 0 or not np.isfinite(time_factor) or not 0 < coordinate_scale <= 1:
        raise ValueError("Invalid time factor or coordinate scale")
    capture = cv2.VideoCapture(str(Path(path)))
    if not capture.isOpened():
        raise ValueError("Cannot open video")
    frames, times = [], []
    try:
        while True:
            ok, image = capture.read()
            if not ok:
                break
            times.append(capture.get(cv2.CAP_PROP_POS_MSEC)/1000*time_factor)
            if coordinate_scale != 1:
                image = cv2.resize(image, None, fx=coordinate_scale, fy=coordinate_scale,
                                   interpolation=cv2.INTER_AREA)
            frames.append(cv2.cvtColor(image, cv2.COLOR_BGR2GRAY))
    finally:
        capture.release()
    t = np.asarray(times, float)
    if len(t) < 2 or not np.isfinite(t).all() or np.any(np.diff(t) <= 0):
        raise ValueError("Decoder did not provide increasing timestamps; supply explicit acquisition times via the Python API")
    return frames, t-t[0]


def jsonable(value):
    if isinstance(value, np.ndarray):
        return value.tolist()
    if isinstance(value, np.generic):
        return value.item()
    if isinstance(value, dict):
        return {k: jsonable(v) for k, v in value.items()}
    if isinstance(value, (list, tuple)):
        return [jsonable(v) for v in value]
    return value

def _duration(mask, interval_start_s, interval_end_s):
    """Length of the selected measurement-interval union, in seconds.

    Endpoints are validated by summarize_patient. Only overlapping/touching
    intervals merge; positive gaps between supported intervals stay missing.
    """
    intervals = sorted(zip(interval_start_s[mask], interval_end_s[mask]))
    if not intervals:
        return 0.
    start, end = intervals[0]
    total = 0.
    for left, right in intervals[1:]:
        if left <= end:
            end = max(end, right)
        else:
            total += end-start
            start, end = left, right
    return float(total+end-start)

"""Reviewable propagation evidence from radial A(s,t).

Keep short and unpaired structures. Pairing ranks propagation coherence rather
than event count; engineering diagnostics do not establish physiological truth.
"""
from dataclasses import dataclass, asdict
import numpy as np
from .amplitude import band_limited_signal


@dataclass(frozen=True)
class RadialWaveConfig:
    # Fit reference is used jointly with order/phase evidence, not as a veto.
    min_fit_r2: float = .5
    synchronous_tolerance_s: float = .5


def _runs(mask):
    return np.flatnonzero(np.diff(np.r_[False, mask, False])).reshape(-1, 2)


def _fit(s, t):
    slope, intercept = np.polyfit(s, t, 1)
    residual = t-(slope*s+intercept)
    total = float(np.sum((t-t.mean())**2))
    return dict(slope=float(slope), intercept=float(intercept),
                r2=float(1-np.sum(residual**2)/total) if total > 1e-20 else None,
                rmse_s=float(np.sqrt(np.mean(residual**2))))


def _arrival_evidence(s, arrival, dt):
    fit = _fit(s, arrival)
    differences = (arrival[None, :] - arrival[:, None])[np.triu_indices(len(s), 1)]
    resolved = abs(differences) > dt
    agreement = float(np.mean(differences[resolved] * fit['slope'] > 0)) if resolved.any() else .5
    extent = abs(fit['slope']) * float(np.ptp(s))
    # Continuous engineering ranking, not a calibrated probability or p-value.
    quality = (max(fit['r2'] or 0., 0.) * max(2*agreement-1, 0.) *
               extent/(extent + 2*fit['rmse_s'] + dt))
    return dict(**fit, order_agreement=agreement, fitted_time_extent_s=extent,
                coherence=float(quality))


def _describe_arrival(ids, arrival, s, dt, phase_fits, config):
    evidence = _arrival_evidence(s[ids], arrival, dt)
    warnings = []
    delta = np.diff(arrival)
    monotone = bool(np.all(delta >= -dt) or np.all(delta <= dt))
    weak_fit = (evidence['r2'] or 0.) < config.min_fit_r2
    phase_conflict = any(p['slope']*evidence['slope'] < 0 for p in phase_fits)
    if not monotone: warnings.append('nonmonotone_arrivals')
    if weak_fit: warnings.append('weak_arrival_fit')
    if phase_conflict: warnings.append('phase_direction_conflict')
    if any((p['r2'] or 0.) < config.min_fit_r2 for p in phase_fits):
        warnings.append('weak_phase_fit')
    if np.ptp(arrival) <= max(dt, config.synchronous_tolerance_s):
        kind = 'synchronous'
    elif not monotone and (weak_fit or phase_conflict):
        kind = 'complex'
    else:
        kind = 'C2F' if evidence['slope'] > 0 else 'F2C'
    return dict(classification=kind, sections=ids.tolist(),
                s_start=float(s[ids[0]]), s_end=float(s[ids[-1]]),
                spatial_span=float(s[ids[-1]]-s[ids[0]]),
                arrival_time_s=arrival.tolist(), arrival_fit_R2=evidence['r2'],
                arrival_fit_RMSE_s=evidence['rmse_s'],
                arrival_time_slope=evidence['slope'], arrival_evidence=evidence,
                velocity_paths_per_s=float(1/evidence['slope']) if kind in ('C2F','F2C') else None,
                phase_arrival_fits=phase_fits, quality_flags=warnings)


def _measure_pair(edge, ridges, filtered, t, s, config):
    first, second = [ridges[edge[name]] for name in ('first', 'second')]
    left = {x['column']: x for x in first['nodes']}
    right = {x['column']: x for x in second['nodes']}
    ids = np.asarray(edge['columns'])
    arrival = []
    for j in ids:
        k, k2 = left[j]['last'], right[j]['first']
        before, after = filtered[k, j], filtered[k2, j]
        arrival.append(t[k] - before/(after-before)*(t[k2]-t[k]))
    dt = float(np.median(np.diff(t)))
    phases = [_arrival_evidence(s[ids], np.array([p[j]['peak_time_s'] for j in ids]), dt)
              for p in (left, right)]
    event = _describe_arrival(ids, np.asarray(arrival), s, dt, phases, config)
    quality = event['arrival_evidence']['coherence']
    for phase in phases:
        quality *= phase['coherence']
    agreeing = sum(p['slope']*event['arrival_time_slope'] > 0 for p in phases)
    # Shared support contributes only in proportion to temporal coherence.
    edge['association_weight'] = len(ids)*quality*(1+agreeing)/3
    event.update(evidence_kind='paired_phase', arrival_marker='between_phase_zero_crossing',
                 association_weight=edge['association_weight'],
                 start_s=min(left[j]['start_s'] for j in ids),
                 end_s=max(right[j]['end_s'] for j in ids),
                 leading_polarity=first['sign'], phase_ridge_ids=[first['id'], second['id']],
                 first_phase_arrival_s=[left[j]['peak_time_s'] for j in ids],
                 second_phase_arrival_s=[right[j]['peak_time_s'] for j in ids],
                 peak_absolute_rate_per_phase=[max(left[j]['amplitude'] for j in ids),
                                               max(right[j]['amplitude'] for j in ids)])
    return event


def _lobes(y, valid, t, threshold):
    filtered = np.full_like(y, np.nan)
    columns = [[] for _ in range(y.shape[1])]
    minimum = max(3, int(np.ceil(12/np.median(np.diff(t)))))
    for col in range(y.shape[1]):
        for run_id, (begin, end) in enumerate(_runs(valid[:, col])):
            if end-begin < minimum:
                continue
            signal = band_limited_signal(y[begin:end, col], t[begin:end])
            filtered[begin:end, col] = signal
            edges = np.r_[0, np.flatnonzero(np.diff(signal >= 0))+1, len(signal)]
            for sequence, (a, b) in enumerate(zip(edges[:-1], edges[1:])):
                # A censored phase cannot establish a complete bipolar event.
                if a == 0 or b == len(signal):
                    continue
                peak = int(a+np.argmax(abs(signal[a:b])))
                amplitude = float(abs(signal[peak]))
                if amplitude <= max(float(threshold[col]), 1e-12):
                    continue
                columns[col].append(dict(column=col, run_id=run_id, sequence=sequence,
                    sign=1 if signal[peak] > 0 else -1, peak_index=int(begin+peak),
                    peak_time_s=float(t[begin+peak]), amplitude=amplitude,
                    first=int(begin+a), last=int(begin+b-1),
                    start_s=float(t[begin+a]), end_s=float(t[begin+b-1])))
    return filtered, columns


def _ridges(columns, t, s):
    nodes=[]
    for column in columns:
        for node in column:
            node['id']=len(nodes);nodes.append(node)
    parent=list(range(len(nodes)))

    def find(i):
        while parent[i] != i:
            parent[i]=parent[parent[i]];i=parent[i]
        return i

    for left, right in zip(columns[:-1], columns[1:]):
        choices=[]
        for a in left:
            for b in right:
                delay=abs(a['peak_time_s']-b['peak_time_s'])
                scale=.5*((a['end_s']-a['start_s'])+(b['end_s']-b['start_s']))
                overlap=min(a['end_s'],b['end_s'])-max(a['start_s'],b['start_s'])
                if a['sign']==b['sign'] and delay<=scale and overlap>=0:
                    choices.append((delay,a['id'],b['id']))
        used_left=set();used_right=set()
        for _, a, b in sorted(choices):
            if a in used_left or b in used_right:continue
            parent[find(a)]=find(b);used_left.add(a);used_right.add(b)
    groups={}
    for node in nodes:groups.setdefault(find(node['id']),[]).append(node)
    ridges=[]
    for group in groups.values():
        if len(group)<3:continue
        group=sorted(group,key=lambda node:node['column'])
        ids=np.array([node['column'] for node in group])
        arrival=np.array([node['peak_time_s'] for node in group])
        ridges.append(dict(id=len(ridges), sign=group[0]['sign'], nodes=group,
                           fit=_fit(s[ids],arrival), center_s=float(np.median(arrival))))
    return ridges


def _phase_edges(ridges):
    edges={}
    for i,a in enumerate(ridges):
        for j in range(i+1,len(ridges)):
            b=ridges[j]
            if a['sign']==b['sign']:continue
            left={node['column']:node for node in a['nodes']}
            right={node['column']:node for node in b['nodes']}
            common=sorted(set(left)&set(right))
            # Adjacent phases must belong to the same continuous track run in
            # each shared column. No phase pairing over a missing interval.
            common=[k for k in common if left[k]['run_id']==right[k]['run_id'] and
                    abs(left[k]['sequence']-right[k]['sequence'])==1]
            if len(common)<3 or np.any(np.diff(common)!=1):continue
            delta=np.array([right[k]['peak_time_s']-left[k]['peak_time_s'] for k in common])
            if not (np.all(delta>0) or np.all(delta<0)):continue
            early,late=(a,b) if delta.mean()>0 else (b,a)
            edges[i,j]=dict(first=early['id'], second=late['id'], columns=common,
                            score=(1,len(common),int(early['sign']<0)))
    return edges


def _pair_phases(ridges, edges):
    """Non-overlapping adjacent phase pairs, without counting both polarities.

    Maximize shared support weighted by propagation coherence. No reward for
    pair count or preferred polarity. Unselected phases remain review evidence.
    """
    neighbors={i:[] for i in range(len(ridges))}
    for i,j in edges:neighbors[i].append(j);neighbors[j].append(i)
    ambiguous=[i for i in neighbors if len(neighbors[i])>1]
    negative=[i for i in neighbors if ridges[i]['sign']<0 and neighbors[i]]
    positive=[i for i in neighbors if ridges[i]['sign']>0 and neighbors[i]]
    if not negative or not positive:return [],ambiguous
    n=len(negative);m=len(positive)
    # Dummy columns permit unmatched phases, including zero-coherence pairs.
    cost=np.zeros((n,m+n),float)
    cost[:,:m]=1
    for row,i in enumerate(negative):
        for col,j in enumerate(positive):
            edge=edges.get(tuple(sorted((i,j))))
            if edge is not None:
                cost[row,col]=-edge['association_weight']
    # Rectangular shortest-augmenting-path assignment (rows <= columns).
    u=np.zeros(n+1);v=np.zeros(m+n+1)
    owner=np.zeros(m+n+1,int);previous=np.zeros(m+n+1,int)
    for row in range(1,n+1):
        owner[0]=row;col=0;minimum=np.full(m+n+1,np.inf);used=np.zeros(m+n+1,bool)
        while True:
            used[col]=True;current_row=owner[col];delta=np.inf;next_col=0
            for j in range(1,m+n+1):
                if used[j]:continue
                reduced=cost[current_row-1,j-1]-u[current_row]-v[j]
                if reduced<minimum[j]:minimum[j]=reduced;previous[j]=col
                if minimum[j]<delta:delta=minimum[j];next_col=j
            u[owner[used]]+=delta;v[used]-=delta;minimum[~used]-=delta
            col=next_col
            if owner[col]==0:break
        while col:
            before=previous[col];owner[col]=owner[before];col=before
    chosen=[]
    for col in range(1,m+1):
        if owner[col] and cost[owner[col]-1,col-1]<0:
            chosen.append(tuple(sorted((negative[owner[col]-1],positive[col-1]))))
    return chosen,ambiguous


def detect_radial_events(signal, valid, time_s, space, *, noise_floor, config=None):
    """Find radial propagation evidence, with an explicit noise scale.

    noise_floor is an absolute A threshold (s^-1), scalar or one per section.
    It must come from a stated noise reference, not per-video robust-z scaling.
    Space stays on the original full cervix-to-fundus axis, without rescaling.
    """
    config=config or RadialWaveConfig()
    y=np.asarray(signal,float);m=np.asarray(valid,bool);t=np.asarray(time_s,float);s=np.asarray(space,float)
    if (y.shape!=m.shape or y.shape!=(len(t),len(s)) or len(t)<3 or len(s)<3 or
            not np.isfinite(t).all() or not np.isfinite(s).all() or np.any(np.diff(s)<=0) or
            np.any((s<0)|(s>1)) or np.any(np.diff(t)<=0) or
            not np.allclose(np.diff(t),np.median(np.diff(t)),rtol=1e-5,atol=1e-9)):
        raise ValueError('Expected matching native-uniform time x ordered normalized-space maps')
    threshold=np.broadcast_to(np.asarray(noise_floor,float),(len(s),))
    if not np.isfinite(threshold).all() or np.any(threshold<0):raise ValueError('Invalid absolute noise floor')
    if not 0<=config.min_fit_r2<=1 or config.synchronous_tolerance_s<0:
        raise ValueError('Invalid radial event support settings')
    filtered,columns=_lobes(y,m&np.isfinite(y),t,threshold)
    ridges=_ridges(columns,t,s);edges=_phase_edges(ridges)
    measured={key:_measure_pair(edge,ridges,filtered,t,s,config) for key,edge in edges.items()}
    pairs,ambiguous=_pair_phases(ridges,edges);events=[]
    for key in pairs:
        events.append(dict(measured[key],event_id='',reviewed=False,
                           phase_pairing_ambiguous=any(i in ambiguous for i in key)))
    used={i for key in pairs for i in key}
    for ridge in ridges:
        if ridge['id'] in used:continue
        nodes=ridge['nodes'];ids=np.array([n['column'] for n in nodes])
        arrival=np.array([n['peak_time_s'] for n in nodes])
        event=_describe_arrival(ids,arrival,s,float(np.median(np.diff(t))),[],config)
        event['quality_flags'].append('single_phase_event_identity_unresolved')
        events.append(dict(event,event_id='',reviewed=False,evidence_kind='single_phase',
            arrival_marker='phase_peak',start_s=min(n['start_s'] for n in nodes),
            end_s=max(n['end_s'] for n in nodes),leading_polarity=ridge['sign'],
            phase_ridge_ids=[ridge['id']],phase_pairing_ambiguous=ridge['id'] in ambiguous,
            first_phase_arrival_s=arrival.tolist(),second_phase_arrival_s=[],
            peak_absolute_rate_per_phase=[max(n['amplitude'] for n in nodes)]))
    for event in events:
        if event['phase_pairing_ambiguous']:
            event['quality_flags'].append('alternative_phase_pairing')
    events.sort(key=lambda event:(np.median(event['arrival_time_s']),event['s_start']))

    return dict(status='automatic_radial_wave_candidates_require_review',config=asdict(config),
        candidate_algorithm='radial_phase_evidence_v2',
        noise_floor_rate=threshold.copy(),filter_band_cpm=[.5,5.],filtered_A=filtered,
        events=events,candidate_count=len(events),
        traveling_candidate_count=sum(e['classification'] in ('C2F','F2C') for e in events),
        ambiguous_phase_ridge_ids=ambiguous,unpaired_ridge_count=len(ridges)-2*len(pairs),
        alternative_phase_pairs=[dict(measured[key],selected=key in pairs)

        event_count=None,event_frequency_cpm=None,
        phase_ridges=[dict(ridge_id=r['id'],sign=r['sign'],sections=[x['column'] for x in r['nodes']],
                           peak_time_s=[x['peak_time_s'] for x in r['nodes']],fit=r['fit']) for r in ridges])
