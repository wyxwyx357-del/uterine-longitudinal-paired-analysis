# Pilot analysis plan

## Step 1 — 固定纵向名单

1. 使用去标识化 `patient_id`；
2. 每次检查有唯一 `exam_id`；
3. 每次检查有患者内顺序 `exam_order = 1, 2, 3, ...`；
4. 主队列要求患者至少有 2 次视频时长 >= 60 s 的合格检查；
5. 患者有 3 次或更多合格检查时全部保留；
6. 缺失保持 NaN，不自动补齐；
7. 不按妊娠结局、特征大小或视频结果选择某两次检查。

输出：
- 患者数；
- 检查数；
- 每位患者检查次数分布；
- 每个变量可用数；
- 视频时长范围。

## Step 2 — 患者内纵向轨迹

先画每位患者所有检查的轨迹：

`exam_1 -> exam_2 -> exam_3 -> ...`

对连续指标计算所有相邻变化：

`delta_k = exam_k - exam_(k-1)`

主要观察：
- 厚度变化 vs VFI变化；
- 厚度变化 vs PI变化；
- VFI/PI变化 vs 临床总蠕动频率变化；
- VFI/PI变化 vs 前/后壁幅度变化。

结果重点呈现：
- 每次检查原始值；
- 每个相邻区间的 delta；
- 每位患者总体轨迹；
- 上升/下降/不变方向；
- delta–delta 散点图。

如果同一患者贡献多个 delta，不把这些 delta 当成来自不同患者的完全独立样本。当前 pilot 以图形和患者内描述为主。

## Step 3 — 结局不一致患者

识别同时具有成功和失败周期的患者。

### 只有一次成功 + 一次失败
直接计算：

`success_minus_failure = success - failure`

### 存在多次成功或多次失败
不挑选最有利的一对。

对每位患者、每个特征分别计算：
- 成功检查的患者内中位数；
- 失败检查的患者内中位数；
- `median_success - median_failure`。

同时保留全部逐次检查轨迹，避免中位数掩盖时间变化。

输出：
- 每位患者成功/失败检查次数；
- 成功水平、失败水平及患者内差值；
- 成功更高 / 更低 / 相同的人数；
- 个体轨迹图。

不把小样本结果解释为正式因果关系或预测证据。

## Step 4 — 逐例检查可能的其他解释

至少核对：
- 检查距移植时间；
- 内膜准备/治疗方案；
- 胚胎阶段、质量、移植个数（如果可用）；
- 视频时长；
- 视频/追踪质量；
- 其他明显的检查条件差异。

## 综合表型

只有在前述分析发现形态、血流和动态指标存在较稳定的共同变化后，才考虑综合表型。

当前不建立：
- 加权总分；
- 自动特征筛选模型；
- 妊娠分类器。
