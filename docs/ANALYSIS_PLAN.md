# Pilot analysis plan

## Step 1 — 固定名单

1. 使用去标识化 patient_id；
2. 每次检查有唯一 exam_id；
3. 主队列要求两次检查视频均 >= 60 s；
4. 缺失保持 NaN；
5. 超过两次检查的患者必须显式指定 pair_order，不由代码自动择优。

输出：
- 患者数；
- 检查数；
- 每个变量可用数；
- 视频时长范围；
- 是否存在超过两次检查的患者。

## Step 2 — 患者内变化

对连续指标计算：

`delta = exam_2 - exam_1`

主要观察：
- 厚度变化 vs VFI变化；
- 厚度变化 vs PI变化；
- VFI/PI变化 vs 临床总蠕动频率变化；
- VFI/PI变化 vs 前/后壁幅度变化。

结果重点呈现：
- 每个指标的前后值；
- delta 中位数与 IQR；
- 上升/下降/不变人数；
- delta–delta 散点图；
- Spearman 相关仅作为探索性描述。

不以 P < 0.05 作为主要目标。

## Step 3 — 结局不一致患者

对同一患者的：
- 失败周期；
- 成功周期

计算：

`success_minus_failure = success - failure`

输出：
- 成功周期更高 / 更低 / 相同的人数；
- 差值中位数与 IQR；
- 每个患者的配对连线图。

不把小样本配对结果解释为正式因果关系或预测证据。

## Step 4 — 逐例检查可能的其他解释

至少核对：
- 检查距移植时间；
- 内膜准备/治疗方案；
- 胚胎阶段、质量、移植个数（如果可用）；
- 视频时长；
- 视频/追踪质量；
- 其他明显的检查条件差异。

## 综合表型

只有在前述分析发现形态、血流和动态指标存在较稳定的共同变化后，才考虑综合表型。

当前不建立：
- 加权总分；
- 自动特征筛选模型；
- 妊娠分类器。
