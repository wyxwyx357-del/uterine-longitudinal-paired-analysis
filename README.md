# Uterine Longitudinal Paired Analysis

用于分析**同一患者多次检查 / 多个周期**的超声变化。患者可以有 2 次、3 次、4 次或更多检查，符合条件的检查全部保留，不强行压缩成两次配对。

重点观察：

- 子宫内膜形态：厚度、容积、分型；
- 血流：VI、FI、VFI、PI、RI、S/D；
- 临床蠕动：正向/反向频率及总频率；
- 自动视频动态特征：前/后壁幅度为优先指标，R2、ER、MSE、M1 为探索性指标。

## 当前研究定位

这是一个小样本 pilot，核心是利用“**患者自己和自己比**”的重复检查结构。

主问题不是建立妊娠预测模型，而是回答：

1. 同一患者多次检查过程中，内膜、血流和动态运动如何变化；
2. 这些指标在患者内部是否存在同步变化；
3. 对同时存在成功和失败周期的患者，成功周期与失败周期是否呈现一致方向的差异；
4. 视频时长、检查时机、治疗方案、胚胎情况等是否可能解释观察到的差异。

## 主队列原则

主分析队列定义为：

- 同一患者至少 2 次可匹配检查；
- 每次纳入分析的视频可用时长 >= 60 s；
- 每次检查有唯一 `exam_id`；
- 使用 `exam_order = 1, 2, 3, ...` 表示该患者检查顺序；
- 符合条件的检查全部保留；
- 缺失保持缺失，不自动填 0。

**不再要求每位患者只能有两次检查，也不自动挑选“最有利”的两次。**

## 当前优先指标

### 内膜
- thickness
- volume
- type（分类变量，单独描述）

### 血流
重点展示：
- VFI
- PI

同时保留：
- VI
- FI
- RI
- S/D

### 蠕动 / 动态
重点展示：
- 临床总蠕动频率 = 正向频率 + 反向频率
- anterior amplitude
- posterior amplitude

探索性：
- R2 frequency
- ER
- MSE
- M1 propagation/activity rate

## 分析顺序

1. 固定纵向主队列与数据完整性；
2. 画每位患者所有检查的个体轨迹；
3. 计算每位患者相邻检查的变化量：`exam_k - exam_(k-1)`；
4. 观察内膜、血流、蠕动在患者内部是否一起变化；
5. 对同时有成功和失败周期的患者做患者内成功/失败比较；
6. 逐例核对治疗方案、检查时间、胚胎情况、视频时长和质量；
7. 只有在前述结果确实显示稳定联合变化后，才考虑综合表型。

## 两次配对只是子分析

如果某个患者恰好只有两次检查，纵向分析自然等价于一次配对差值。

如果患者有 3 次或更多检查：
- 全部检查保留；
- 全部相邻变化保留；
- 不人为删成两次；
- 后续如需统计建模，再使用适合重复测量/患者聚集结构的方法。

## 不做的事情

当前 pilot 不以以下内容为目标：

- LASSO / SVM / XGBoost / 深度学习；
- 为提高 AUC 搜索特征或参数；
- 把 R2/M1 直接解释成真实生理波频率；
- 把 MSE 直接解释成已验证的双壁协调性生物标志物；
- 用缺失值自动写 0；
- 在公开仓库上传患者姓名、门诊号、原始临床表、视频、检查截图或任何可识别信息。
